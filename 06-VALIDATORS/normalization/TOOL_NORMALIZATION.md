# توحيد نتائج الأدوات الخارجية (Tool Result Normalization)

## 1. مبادئ توحيد النتائج
- لا يعتمد نظام WebForge OS على أداة فحص محددة حصراً، بل يوفر طبقة توحيد وسيطة (`ToolResultNormalizer`) تستقبل المخرجات المتنوعة لمختلف أدوات الفحص وتترجمها إلى البنية الدلالية القياسية لـ WebForge.
- الحفاظ التام على أصل البيانات والمصدر (Source Provenance) وتوثيق اسم الأداة وإصدارها ومعاملات تشغيلها.

---

## 2. جدول مطابقة تصنيفات الأدوات الشائعة

| تصنيف الأداة الخارجية | حالة WebForge المكافئة | مستوى الخطورة المعياري | المعالجة |
| :--- | :--- | :--- | :--- |
| `error` / `vulnerability` / `blocker` | `FAIL` | `CRITICAL` أو `HIGH` | توليد سجل نتيجة أمنية `Finding` وحظر البوابة |
| `warning` / `minor` / `style` | `WARNING` | `LOW` أو `INFORMATIONAL` | توثيق كملاحظة تحسينية غير حاظرة |
| `info` / `passed` / `clean` | `PASS` | N/A | توثيق كدليل اجتياز للفحص |
| `skipped` / `unsupported` | `NOT_APPLICABLE` أو `ENVIRONMENT_LIMITATION` | N/A | توثيق سبب التخطي في سجل الفحص |
| `crash` / `timeout` / `syntax_error` | `INSUFFICIENT_EVIDENCE` | `HIGH` (للفحوصات الحرجة) | تسجيل إخفاق الأداة وإعادة المحاولة في بيئة معزولة |

---

## 3. التعامل مع المخرجات غير الموثوقة (Untrusted Tool Outputs)
- تُعامل مخرجات الأدوات الخارجية كمدخلات غير موثوقة ويتم تنقيتها لمنع هجمات حقن النصوص أو المسارات داخل تقارير WebForge.
- إخفاء وتجريد أي أسرار أو مفاتيح قد تظهر عرضاً في سجلات الأدوات الخارجية قبل تضمينها في التقارير.
