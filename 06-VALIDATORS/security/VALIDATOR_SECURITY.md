# أمان وعزل أدوات التحقق (Validator Tooling Security)

## 1. التهديدات الأمنية لأدوات التحقق
تُعد أدوات التحقق بحد ذاتها أصولاً حساسة قد تتعرض للاستغلال في حال فحص مستودعات أو شيفرات خبيثة:
- **حقن الأوامر والمسارات (Command & Path Traversal Injection)**: عبر أسماء ملفات خبيثة أو معاملات مدخلة بصورة غير منقاة.
- **حقن التوجيهات غير المباشر (Indirect Prompt Injection)**: عبر تعليقات برمجية أو ملفات تهيئة تسعى لتوجيه وكيل الفحص نحو تخطي القواعد.
- **تسريب الأسرار (Secret Exfiltration)**: عبر تضمين مفاتيح البيئة في استدعاءات الأدوات الخارجية أو تقارير الفحص.

---

## 2. الضوابط الدفاعية الحتمية للمدققات
- **التشغيل للقراءة فقط (Read-Only Execution)**: تشغيل كافة المدققات بصلاحيات قراءة فقط لمنع أي تعديل تخريبي على المستودع أثناء الفحص.
- **عزل وسائط التنفيذ (Sandbox Isolation)**: حظر استدعاء أوامر الصدفة المباشرة بدون تمرير المعاملات كمصفوفات محكمة وبدون قشور تنفيذية (`shell: false`).
- **التكامل مع حراس المستودع (Untrusted Repository Guard)**: إخضاع أي مستودع خارجي للفحص التمهيدي بحارس المستودع غير الموثوق قبل السماح بتشغيل أي مدقق عليه.
- **تنقية التقارير والمخرجات (Redaction & Sanitization)**: حظر طباعة أو تسجيل الأسرار وكلمات المرور والرموز المميزة في تقارير التحقق.
