# طبقة التحقق وبوابات الجودة (WebForge OS Validation & Quality Gates Layer)

## 1. النطاق والهدف المعماري
تمثل طبقة `06-VALIDATORS/` المحرك المعرفي والتنفيذي الحاكم للتحقق من مطابقة المشروعات والمستودعات البرمجية لقواعد ومواصفات WebForge OS (المحددة في `01-KNOWLEDGE` و `03-DESIGN` و `04-ENGINEERING` و `05-SECURITY`).

تحدد هذه الطبقة **ماذا يجب التحقق منه** و **كيف يتم تقييم الأدلة التثبيتية** و **معايير الفصل بين النجاح والإخفاق** في بوابات الجودة (Quality Gates) بصورة حتمية ومستقلة تماماً عن المكدس التقني (Stack-Agnostic).

## 3. المبادئ الحاكمة الحتمية
1. **التحقق القائم على الأدلة (Evidence-Based Verification)**: لا يُقبل أي ادعاء أو اجتياز دون توفر دليل تثبيتي صريح وقابل لإعادة الإنتاج.
2. **استقلال التحقق عن المكدس (Stack-Agnostic Validation)**: توفر الطبقة عقوداً وتصنيفات مجردة تحدد ما يجب إثباته وتترك للمشروع حرية استخدام الأدوات المناسبة لبيئته.
3. **الفصل بين النجاح الفردي والاعتماد النهائي**: يُعد اجتياز الفحص الفردي (`PASS`) خطوة أولى، ولا تصبح القاعدة معتمدة (`VERIFIED`) إلا بعد اكتمال التحقق المستقل وكفاية الأدلة.
4. **أمان أداة التحقق (Validator Tooling Security)**: معاملة مخرجات الأدوات الخارجية والمستودعات المفحوصة كبيانات غير موثوقة (Untrusted Inputs) وتطبيق العزل وحظر حقن الأوامر والمسارات.
