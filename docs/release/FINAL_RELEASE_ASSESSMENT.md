## 3. الحدود والمعوقات المعترف بها (Recognized Limitations & Boundaries)

1. **التحقق السحابي غير المباشر لـ GitHub Actions**: تم إعداد مصفوفة تشغيل متعددة الأنظمة (`ubuntu-latest` و `windows-latest` عبر Node 18, 20, 22)، مع ترتيب صارم يفرض تشغيل الانحدار الشامل (`npm test`) قبل تسجيل الأدلة وتفعيل بوابة الإصدار، وقصر رفع الأدلة على حالات النجاح (`if: success()`).
2. **صلاحيات الروابط الرمزية وخصائص الملفات على Windows**: تتطلب بعض أنظمة Windows تشغيل Developer Mode لإنشاء الروابط الرمزية؛ ويتم توثيق تخطيها صراحة كـ `[SKIPPED]`. كما تقتصر استعادة الحالة (Snapshot Rollback) على المحتوى المشفر (SHA-256) وهيكل المجلدات وأهداف الروابط الرمزية وصلاحيات POSIX حيثما أمكن، مع استثناء بيانات ACLs و xattr الخارجة عن نطاق مساحة عمل المستخدم.
3. **الفصل بين الاختبار المؤتمت والقبول البشري**: اجتياز اختبارات CI الآلية وبوابة الاعتماد الحتمية (`bin/release-gate.js`) يؤهل الإصدار للانتقال إلى مرحلة الاعتماد النهائي، ولا يلغي الحاجة إلى إجراء الجلسة التفاعلية البشرية الموثقة في `MANUAL_TESTING_GUIDE.md`.
