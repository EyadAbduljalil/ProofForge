## 3. الحدود والمعوقات المعترف بها (Recognized Limitations & Boundaries)

1. **التحقق السحابي غير المباشر لـ GitHub Actions**: تم إعداد مصفوفة تشغيل متعددة الأنظمة (`ubuntu-latest` و `windows-latest`)، لكن إثبات التنفيذ النهائي يرتبط بمخرجات التشغيل الفعلية داخل حساب GitHub.
2. **صلاحيات الروابط الرمزية على Windows**: تتطلب بعض أنظمة Windows تشغيل Developer Mode أو صلاحيات المسؤول لإنشاء الروابط الرمزية؛ ويتم توثيق تخطيها صراحة كـ `[SKIPPED]` دون منح نجاح زائف.
3. **الفصل بين الاختبار المؤتمت والقبول البشري**: اجتياز اختبارات CI الآلية لا يلغي الحاجة إلى إجراء الجلسة التفاعلية البشرية الموثقة في `MANUAL_TESTING_GUIDE.md`.
