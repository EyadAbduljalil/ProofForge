# هندسة المعالجة الهيكلية للأخطاء وحماية البيانات
## Error Engineering, Structural Error Handling & Information Leak Prevention

---

## 1. مبادئ معالجة الأخطاء (Error Engineering Principles)

1. **حظر تسريب التفاصيل الداخلية (Zero Internal Leakage)**:
   - يُمنع منعاً باتاً إرسال تتبع مكدس الاستدعاءات (Stack Traces)، استعلامات SQL الفاشلة، مسارات الملفات الفيزيائية على الخادم، أو بيانات الإصدارات التقنية إلى العميل.
2. **التمييز الدلالي بين فئات الأخطاء**:
   - `Validation Error (400)`: أخطاء صحة المدخلات.
   - `Authentication Error (401)`: غياب أو انتهاء صلاحية الهوية.
   - `Authorization Error (403)`: انعدام الصلاحية للمورد المطلوب.
   - `Not Found (404)`: المورد غير موجود أو مخفي لأسباب أمنية لمنع كشف الوجود (Anti-Enumeration).
   - `Conflict / Concurrency (409)`: تعارض تزامن أو تكرار مفتاح.
   - `Internal Error (500)`: خطأ غير متوقع يتم تسجيله داخلياً برقم تتبع عشوائي وإرجاع رسالة آمنة ومحايدة للمستخدم.
3. **أرقام التتبع الموحدة (Error Correlation ID)**:
   - تزويد كل استجابة خطأ بمعرف فريد (`error_id` أو `correlation_id`) يتيح للمطورين والأنظمة مراجعة السجلات الداخلية دون كشفها للعميل.
