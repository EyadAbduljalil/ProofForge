# الضوابط الأمنية ومكافحة حقن القوالب (Template Security Standards)

## 1. التهديدات ومكافحة التجاوز
- **حظر تعليمات الالتفاف (Anti-Bypass Protection)**: يُحظر تضمين أي توجيهات تطالب بتجاوز بوابات الجودة أو تجاهل القواعد الكنسية في القوالب.
- **عزل القوالب المعرفية**: تُعامل القوالب كبيانات هيكلية غير تنفيذية (`Declarative Data`).
- **خلو القوالب من الأسرار**: حظر تضمين أي مفاتيح API أو كلمات مرور في نماذج القوالب.
