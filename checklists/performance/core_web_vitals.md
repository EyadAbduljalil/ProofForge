# قائمة التحقق من مؤشرات الويب الحيوية (Core Web Vitals Checklist)

- [ ] **LCP (Largest Contentful Paint)**: أقل من 2.5 ثانية عبر تحسين أولوية تحميل صورة البطل والخطوط الأساسية.
- [ ] **INP (Interaction to Next Paint)**: أقل من 200 ملي ثانية عبر تجنب حظر الخيط الرئيسي (Main Thread) وتقسيم المهام الطويلة.
- [ ] **CLS (Cumulative Layout Shift)**: أقل من 0.1 عبر حجز مساحات ثابتة للإعلانات والصور والمحتوى الديناميكي.
