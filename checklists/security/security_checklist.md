# قائمة التحقق الأمني الشاملة (Comprehensive Security Checklist)

- [ ] **المصادقة وإدارة الجلسات**:
  - [ ] كلمات المرور مشفرة بخوارزمية Argon2id أو Bcrypt.
  - [ ] الرموز مخزنة في ملفات تعريف ارتباط ذات سمات `HttpOnly; Secure; SameSite=Lax/Strict`.
  - [ ] قفل الحساب وتحديد معدل الطلبات لمسارات تسجيل الدخول واستعادة الحساب.
  - [ ] إبطال الجلسات السابقة عند تسجيل الخروج أو تغيير كلمة المرور.
- [ ] **الصلاحيات والتحكم بالوصول**:
  - [ ] فحص ملكية المورد في كافة عمليات القراءة والتعديل والحذف (منع IDOR).
  - [ ] تطبيق نموذج الصلاحيات (RBAC) ومنع تصعيد الصلاحيات الأفقي والرأسي.
  - [ ] الرفض الافتراضي لأي مسار غير مصرح به صراحة.
- [ ] **حماية المدخلات والاستعلامات**:
  - [ ] التحقق الصارم من كافة المخططات من طرف الخادم (Server-side Schema Validation).
  - [ ] استخدام الاستعلامات المجهزة حصراً ومنع حقن SQL / NoSQL.
  - [ ] ترميز المخرجات (Output Encoding) لمنع ثغرات XSS.
  - [ ] التحقق من توقيع الـ Webhooks عبر HMAC.
- [ ] **رؤوس الأمان والبيئة**:
  - [ ] تفعيل HSTS, CSP, X-Frame-Options, X-Content-Type-Options.
  - [ ] عزل المفاتيح والرموز في متغيرات البيئة والتأكد من عدم رفعها في Git.
  - [ ] حظر إرجاع أخطاء الخادم التفصيلية (Stack Traces) إلى العميل.
