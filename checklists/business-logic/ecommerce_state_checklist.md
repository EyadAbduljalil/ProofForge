# قائمة تدقيق حالات التجارة الإلكترونية (Ecommerce State Transitions Checklist)

- [ ] هل يمنع النظام إلغاء الطلب إذا كان في حالة "قيد الشحن" أو "تم التسليم" إلا عبر تدفق الإرجاع؟
- [ ] هل يتم تحرير المخزون المحجوز فوراً في حال فشل عملية الدفع أو انتهاء مهلتها؟
- [ ] هل يتم فحص حدود استخدام الكوبون (العدد الإجمالي والعدد للمستخدم الواحد) داخل معاملة ذرية متزامنة؟
