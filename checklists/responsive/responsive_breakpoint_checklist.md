# قائمة التحقق من التجاوب والشاشات (Responsive Breakpoints Checklist)

- [ ] **شاشات الهواتف الصغيرة (360px - 390px)**:
  - [ ] عدم وجود أي تمرير أفقي غير مقصود (Zero Horizontal Scroll).
  - [ ] القائمة العلوية تتحول إلى قائمة منسدلة أو درج جانبي سلس.
  - [ ] حجم أهداف اللمس لا يقل عن 44x44px.
  - [ ] النصوص مقروءة بوضوح دون تداخل.
- [ ] **شاشات الأجهزة اللوحية (768px - 1024px)**:
  - [ ] تكيف الشبكات من 3 أعمدة إلى عمودين بشكل انسيابي.
  - [ ] الجداول تتكيف وتوفر تمرير داخلي منظم أو تتحول إلى بطاقات.
- [ ] **شاشات الحواسيب والشاشات الكبيرة (1280px - 1920px)**:
  - [ ] تحديد عرض أقصى للحاوية لمنع تمدد المحتوى بشكل غير مريح.
  - [ ] تباعد متزن وهوامش كافية ومريحة للعين.
