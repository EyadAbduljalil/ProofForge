# قائمة التحقق من إمكانية الوصول والتوافق الشامل (WCAG 2.2 AA Checklist)

- [ ] **التنقل عبر لوحة المفاتيح**:
  - [ ] إمكانية الوصول لكافة الروابط والأزرار والحقول باستخدام زر `Tab`.
  - [ ] مؤشر تركيز واضح ومرئي للعين عند التنقل بلوحة المفاتيح.
  - [ ] إغلاق النوافذ المنبثقة والقوائم باستخدام زر `Escape`.
  - [ ] حبس التركيز (Focus Trap) داخل النوافذ المنبثقة النشطة وإرجاعه للعنصر الأصلي عند الإغلاق.
- [ ] **التباين والمقروئية**:
  - [ ] نسبة التباين للنصوص العادية 4.5:1 على الأقل.
  - [ ] نسبة التباين للعناصر الرسومية والأزرار 3:1 على الأقل.
  - [ ] دعم الوضع الفاتح والداكن مع الحفاظ على نسب التباين المطلوبة.
- [ ] **الدلالات والـ ARIA**:
  - [ ] وجود عنوان `<h1>` واحد فقط في الصفحة مع تسلسل هرمي منطقي للعناوين.
  - [ ] كافة الصور تحتوي على نصوص بديلة توضيحية `alt` أو فارغة للصور الديكورية.
  - [ ] الأزرار التي لا تحتوي على نصوص مرئية (مثل أزرار الأيقونات) تحتوي على `aria-label`.
  - [ ] دعم تفضيل تقليل الحركة `@media (prefers-reduced-motion: reduce)`.
