# مرحلة اكتشاف المكدس التقني والقدرات (DETECT)

## المعرّف: `LFC-AI-DETECT-001`
## المرحلة: 3 من 10 في دورة حياة الوكيل
## الحالة: `ACTIVE`

---

## 1. الغرض
استكشاف وتحديد المكدس التقني الحقيقي للمشروع ومحركات التشغيل المتوفرة دون أي افتراضات مسبقة، للتكيف التام مع بيئة العمل وفق قاعدة:
**"اكتشف -> صغ النموذج -> تكيف" (Detect -> Model -> Adapt)** بدلاً من "افترض وافرض" (Assume -> Force).

---

- **إدارة الحزم والتبعيات**: npm / yarn / pnpm / pip / uv.
- **طبقة تخزين البيانات**: SQLite / PostgreSQL / MySQL / MongoDB / In-Memory / File-based.
- **أطر الاختبارات**: Node Test Runner / Jest / Vitest / Mocha / Playwright.
- **القدرات الخارجية المتاحة**: Docker / Redis / Message Queues / Cloud APIs.
