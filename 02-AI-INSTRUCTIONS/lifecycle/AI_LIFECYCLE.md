## 2. جدول مراحل دورة الحياة والمدخلات والمخرجات

| المرحلة | الهدف الأساسي | المدخلات الإلزامية | المخرجات المتوقعة |
| :--- | :--- | :--- | :--- |
| **1. UNDERSTAND** | استيعاب الأهداف والقيود | نص المهمة / الطلب | نطاق العمل ومعايير القبول |
| **2. INSPECT** | فهم الكود القائم | مسارات الملفات والاعتماديات | خريطة المكونات المتأثرة |
| **3. DETECT** | التكيف مع المكدس التقني | ملفات التكوين والبيئة | ملف تعريف المكدس (Stack Profile) |
| **4. SELECT RULES** | ربط القواعد المعيارية | الـ 36 قاعدة في `01-KNOWLEDGE/` | مصفوفة القواعد المنطبقة |
| **5. DECIDE** | حل التعارضات المعمارية | مصفوفة هرمية السلطة | سجل القرار (Decision Record) |
| **6. PLAN** | هيكلة خطوات العمل | نطاق المهمة والقواعد | خطة العمل ونقاط الاستعادة |
| **7. IMPLEMENT** | كتابة وتعديل الشيفرة | خطة العمل والكود القائم | تعديل برمجي آمن ومكتمل |
| **8. VALIDATE** | فحص السلامة والجودة | حزم الاختبارات والمدققات | نتائج الفحص الآلي |
| **9. VERIFY EVIDENCE** | ربط الادعاء بالبرهان | مخرجات الفحص والاختبارات | سجل الأدلة الموثق |
| **10. REPORT** | إبلاغ المستخدم بالنتيجة | سجل الأدلة والقرارات | التقرير النهائي والتوقف |
