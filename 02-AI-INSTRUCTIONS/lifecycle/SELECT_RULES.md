## 2. مصفوفة تقييم حالة الانطباق (Applicability States)
لكل قاعدة مرشحة، يحدد الوكيل إحدى الحالات الخمس التالية:
1. **APPLICABLE (منطبقة)**: تنطبق على سياق المهمة وكود المشروع ويجب الالتزام بها وفحصها.
2. **NOT_APPLICABLE (غير منطبقة)**: لا تنطبق على طبيعة المشروع (مثل قواعد SQL في تطبيق ثابت لا يستخدم قواعد بيانات).
3. **ENVIRONMENT_LIMITATION (محدودية بيئية)**: منطبقة نظرياً ولكن البيئة الحالية تفتقر للخدمة اللازمة لتنفيذها بالكامل.
4. **NOT_TESTED (لم تُختبر بعد)**: منطبقة وتنتظر مرحلة التحقق والاختبار.
5. **INSUFFICIENT_EVIDENCE (أدلة غير كافية)**: لا تتوفر معطيات كافية لتأكيد الامتثال.

## 3. معايير الانتقاء الإلزامي لقواعد الأمان
- قواعد الأمان الحرجة المصنفة كـ `CRITICAL` (مثل `SEC-AUTH-001`, `SEC-AUTHZ-001`, `SEC-INJ-001`) لا يجوز استبعادها إذا كان المسار البرمجي يتعامل مع مصادقة أو بيانات أو استعلامات.
