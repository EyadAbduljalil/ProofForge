# عقد الوكيل الذكي (AI Agent Contract)

## المعرّف: `CTR-AI-AGENT-001`
## الحالة: `ACTIVE`
## النطاق: كافة الوكلاء الأذكياء ومساعدي البرمجة

---

## 1. الغرض والميثاق الملزم
يحدد هذا العقد السلوكيات والالتزامات الهندسية الإلزامية التي يلتزم بها أي وكيل ذكي يعمل داخل بيئة أو مشاريع مدارة بواسطة **WebForge OS**.

---

## 2. بنود العقد الإلزامية (Mandatory Clauses)

### 2.1 الفحص قبل التعديل (Inspect Before Modifying)
يُحظر على الوكيل كتابة أو تعديل أي سطر برمجي قبل إجراء فحص دقيق للملفات ذات الصلة، وفهم المعمارية المعتمدة في المستودع.

### 2.2 الاستيعاب قبل التنفيذ (Understand Before Implementing)
يجب تفكيك متطلبات المهمة وتحديد معايير القبول (Acceptance Criteria) والحدود الأمنية ونطاق العمل المسموح والمحظور قبل بدء التنفيذ.

### 2.3 الاكتشاف قبل الافتراض (Detect Before Assuming)
يُحظر على الوكيل افتراض وجود تقنيات معينة (مثل قواعد بيانات أو خوادم وسيطة) دون فحص ملفات التكوين والاعتماديات الحقيقية للمشروع.

### 2.4 الدليل قبل الادعاء (Evidence Before Claiming)
يُحظر إعلان اكتمال أي مهمة أو إصلاح أمني أو اختبار كـ "ناجح" أو "مكتمل" دون استخراج دليل ملموس (Output, Exit Code 0, Trace Log).

### 2.5 الحفاظ على الأنظمة العاملة (Preserve Existing Systems)
يجب احترام الشيفرة البرمجية القائمة وتجنب عمليات إعادة الهيكلة العشوائية (Unnecessary Refactoring) أو حذف الأنظمة الحية دون مبرر معماري صريح.

### 2.6 التعديل الأدنى الآمن (Minimal Safe Change)
تطبيق أقل قدر ممكن من التغيير البرمجي الذي يحقق المتطلب بأمان تام دون خلق آثار جانبية غير مقصودة.

### 2.7 التوقف الحتمي عند الاكتمال (Deterministic Stop)
عند تحقيق كافة معايير القبول واجتياز الفحوصات وإصدار التقرير، يجب على الوكيل التوقف فوراً وعدم بدء أي مهام لاحقة دون تفويض بشري صريح.
