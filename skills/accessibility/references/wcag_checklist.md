# WCAG 2.2 AA Core Checklist

1. **Non-text Content (1.1.1):** All images and SVG icons have meaningful `alt` or `aria-label`, or `aria-hidden="true"`.
2. **Keyboard Accessible (2.1.1):** All functionality operates via keyboard without specific timings.
3. **No Keyboard Trap (2.1.2):** Focus never gets stuck inside a sub-component.
4. **Focus Visible (2.4.7):** Any keyboard operable element has a clearly visible focus indicator.
5. **Contrast Minimum (1.4.3):** 4.5:1 for normal text, 3:1 for large text.
6. **Name, Role, Value (4.1.2):** Custom interactive components expose standard roles and states.
