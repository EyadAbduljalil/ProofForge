# ProofForge Technical SEO Checklist

1. **Title Tag:** 50 - 60 characters with primary keyword.
2. **Meta Description:** 120 - 155 characters clear call to action.
3. **Canonical Link:** Explicit `<link rel="canonical" href="...">`.
4. **Robots.txt & Sitemap:** Valid `public/robots.txt` referencing `sitemap.xml`.
5. **Image Alt Attributes:** Descriptive, non-keyword-stuffed alt attributes on all informative images.
