# مهارة هندسة الواجهات الأمامية (Frontend Engineering Skill)

## 1. الهدف
تطوير واجهات مستخدم حديثة، سريعة، ومبنية على مكونات معيارية قابلة لإعادة الاستخدام، مع إدارة متقدمة للحالات، ومنع أي كود عشوائي.

## 2. الممارسات القياسية
1. **معمارية المكونات**: تقسيم الواجهات إلى مكونات ذرية (Atoms, Molecules, Organisms).
2. **إدارة الحالة**: استخدام الحالات المحلية للحالات البسيطة، وإدارة الحالة العامة فقط عند الحاجة الحقيقية مع منع إعادة التصيير الزائدة.
3. **التكامل مع الـ API**: استخدام خطافات مخصصة (Custom Hooks) لمعالجة جلب البيانات مع دعم التخزين المؤقت وإعادة المحاولة.
4. **معالجة الحالات الخمس**: التحميل، النجاح، الفراغ، الخطأ، والفشل الجزئي لكل مكون معتمد على البيانات.
