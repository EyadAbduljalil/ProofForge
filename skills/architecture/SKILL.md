# مهارة التخطيط والتصميم المعماري (Architecture Skill)

## 1. الهدف
توجيه الذكاء الاصطناعي والمهندس لتحديد وتوثيق البنية التحتية والمعمارية لأي مشروع ويب قبل البدء في كتابة الكود البرمجي، مع ضمان الفصل الصارم للمسؤوليات وقابلية التوسع.

## 2. الخطوات الإلزامية
1. **تحليل النطاق والمتطلبات**: تحديد نمط التطبيق (Monolith, Modular Monolith, Microservices, Serverless).
2. **اختيار المكدس التقني (Tech Stack)**: تحديد لغة البرمجة، أطر العمل، وقواعد البيانات بناءً على طبيعة الأحمال وتطلعات المشروع.
3. **توثيق القرارات المعمارية (ADRs)**: إنشاء سجلات موثقة لكل قرار استراتيجي داخل `docs/decisions/`.
4. **رسم مخططات التدفق والبيانات**: إنشاء مخططات Mermaid واضحة توضح حركة البيانات بين العميل، الخادم، وقواعد البيانات والخدمات الخارجية.

## 3. المعايير والمخرجات
- هيكل مجلدات معياري متوافق مع مبادئ Clean Architecture.
- ملف `ARCHITECTURE.md` شامل يحدد مسؤوليات كل طبقة.
