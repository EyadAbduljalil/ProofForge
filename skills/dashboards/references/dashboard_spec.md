# ProofForge Dashboard & Visualization Standard

1. **Monospace for Numbers:** Always format financial figures, metrics, and timestamps in tabular monospace (`font-mono font-variant-numeric: tabular-nums`).
2. **Accessible Charts:** Every chart must include an accessible data table alternative for screen readers (`sr-only`).
3. **Empty & Error State:** Analytics widgets must gracefully handle missing data intervals without collapsing layout.
