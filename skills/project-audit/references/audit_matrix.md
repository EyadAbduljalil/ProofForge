# ProofForge 5-Dimension Audit Scoring Matrix

1. **Security (Weight: 35%):** Authentication, Authorization (anti-IDOR), Injection prevention, CSRF/CORS/CSP, Secret hygiene.
2. **Architecture (Weight: 25%):** Clean Architecture boundaries, Invariant validation, State machines, ADR documentation.
3. **Quality & Evidence (Weight: 20%):** Strict typing, Clean lint, Automated unit/integration test coverage.
4. **UX & Accessibility (Weight: 10%):** WCAG 2.2 AA compliance, RTL/LTR parity, Anti-slop craftsmanship.
5. **Operational Readiness (Weight: 10%):** 12-Factor adherence, Health probes, Production build verification.
