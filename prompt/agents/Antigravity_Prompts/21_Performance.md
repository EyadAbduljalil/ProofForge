# Backend & Frontend Performance Optimization

قم بتحسين أداء المتجر الإلكتروني (Performance Optimization) على مستوى الباك إند، قاعدة البيانات، والفرونت إند لتحقيق أقصى سرعة استجابة وتجربة قوية.

## 1. تحسين استعلامات قاعدة البيانات (Database Query Optimization)
* **حل مشكلة N+1 Query**: فحص واستبدال كافة الاستعلامات المتكررة بالتحميل المسبق للعلاقات (e.g. `include` / `select` في Prisma ORM) أو الاستعلامات التجميعية (Joins).
* **تحديد الحقول المطلوبة (Selective Field Queries)**: استخراج الحقول الضرورية فقط عند العرض في القوائم (تجنب جلب البيانات النصية الضخمة عند استعراض قائمة المنتجات).
* **ضبط الفهارس (Indexes Optimization)**: مراجعة خطط تنفيذ الاستعلامات (Explain Analyze) وإضافة فهارس مركبة (Composite Indexes) على الحقول الأكثر تكراراً في الفلترة والترتيب.

## 2. التخزين المؤقت وتحسين الـ API (Selective Caching & Payload Efficiency)
* **استراتيجية التخزين المؤقت البسيطة (Selective Lightweight Caching)**:
  * تطبيق caching خفيف للبيانات شبه الثابتة التي تقرأ بكثرة ولا تتغير باستمرار (مثل قائمة التصنيفات الرئيسة، إعدادات المتجر العامة) في الذاكرة السريعة (In-Memory / Redis).
  * حظر إضافة حلول كاش معقدة أو متداخلة دون حاجة حقيقية لتجنب مشاكل مزامنة البيانات وتلف الكاش (Cache Invalidation complexity).
* **تقليل حجم الـ Payload والتقسيم الصفحي**:
  * التأكد من أن استجابة API لا تتعدى البيانات المطلوبة للمكون الحالي.
  * تفعيل ضغط الاستجابات (Gzip / Brotli compression).

## 3. تحسين الفرونت إند والـ Bundle (Frontend Asset & Render Optimization)
* **تحسين وتحميل الصور (Image Optimization & Lazy Loading)**:
  * تحويل الصور واستخدام صيغ حديثة خفيفة (WebP / AVIF).
  * دعم أحجام صور متجاوبة (Responsive Image Sizes `srcset`) لتحميل الصورة المناسبة لشاشة المستخدم.
  * تفعيل التحميل التكاسلي للصور (`loading="lazy"`) خارج نطاق الشاشة الأولي.
* **تقليل حجم حزمة الكود (Code Splitting & Bundle Size Reduction)**:
  * تقسيم كود الفرونت إند (Dynamic Imports / React.lazy) لتحميل صفحات المتجر حسب الطلب وعدم تحميل صفحة Admin أو Checkout عند تصفح الصفحة الرئيسية.
  * فحص واستبعاد المكتبات الخارجية الضخمة غير المستعملة.
* **تحسين رندر المكونات (Prevent Unnecessary Re-renders)**:
  * الاعتماد على ممارسات إدارة الحالة الفعالة وتقليل إعادة رندر العناصر الثابتة.
