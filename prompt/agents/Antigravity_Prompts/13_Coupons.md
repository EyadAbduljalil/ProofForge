# Coupons & Discount Engine

أنشئ نظام محرك الخصومات والكوبونات (Coupons & Discount Engine) لإتاحة الخصومات الذكية للعملاء مع التحكم الكامل وسيرفر-سايد سكيورتي.

## 1. أنواع وقواعد الكوبونات (Coupon Types & Rules)
* **أنواع الخصم (Discount Types)**:
  * `PERCENTAGE`: نسبة مئوية من إجمالي المنتجات المؤهلة (مثل 15%).
  * `FIXED_AMOUNT`: مبلغ خصم ثابت (مثل 50 SAR).
* **الشروط والقيود (Coupon Constraints)**:
  * `minOrderAmount`: الحد الأدنى لقيمة الطلب لتطبيق الكوبون.
  * `maxDiscountAmount`: الحد الأقصى لمبلغ الخصم في حالة الخصم المئوي (مثل خصم 20% بحد أقصى 100 SAR).
  * `usageLimit`: إجمالي عدد مرات الاستخدام المتاحة للكوبون عبر المتجر ككل.
  * `usageLimitPerUser`: الحد الأقصى لمرات استخدام الكوبون للعميل الواحد (مثل مرة واحدة لكل مستخدم).
  * `startDate` & `endDate`: فترة صلاحية الكوبون الزمانية.
  * `isActive`: مفتاح التفعيل أو التعطيل السريع.

## 2. التحقق والحسابات على السيرفر (Server-Side Coupon Validation)
* **الحساب والتحقق الحصري على السيرفر**:
  * منع حساب قيمة الخصم أو قبولها من Frontend نهائياً.
  * إنشاء API mخصص لتطبيق واختبار الكوبون (`POST /api/coupons/apply`) يقوم بالتحقق من:
    1. وجود الكوبون وصحته (`code`).
    2. حالة التفعيل (`isActive == true`).
    3. الصلاحية الزمانية (`startDate <= NOW() <= endDate`).
    4. عدم تجاوز سقف الاستخدام الكلي (`usageCount < usageLimit`).
    5. عدم تجاوز سقف استخدام العميل المحدد (`userUsageCount < usageLimitPerUser`).
    6. تحقق الحد الأدنى لقيمة السلة (`subtotal >= minOrderAmount`).
* **حساب الخصم الصافي**:
  * حساب قيمة الخصم بدقة وتطبيق الحد الأقصى إن وجد (`Math.min(calculatedDiscount, maxDiscountAmount)`).
  * ربط الكوبون برمز الطلب في جلسة Checkout ومسحه في حالة الإلغاء أو عدم اكتمال الطلب.

## 3. إدارة الأدمن والتقارير (Admin Coupon Management)
* واجهة وAPIs مخصصة للـ Admin تمكّنه من:
  * **Create**: إنشاء كوبون جديد بترميز فريد وتحديد كامل القواعد والقيود.
  * **Update**: تعديل صلاحيات وقواعد الكوبونات الحالية.
  * **Disable/Enable**: تفعيل أو إيقاف الكوبون فورياً عند الحاجة.
  * **Delete**: حذف أو أرشفة الكوبون غير المستعمل.
  * **View Usage**: استعراض إحصائيات استخدام الكوبون (عدد المرات، المبالغ المخصومة، والطلبات المرتبطة به).
