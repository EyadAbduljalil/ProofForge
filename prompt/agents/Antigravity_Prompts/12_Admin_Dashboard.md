# Admin Dashboard & Management System

أنشئ لوحة تحكم كاملة وشاملة للمسؤولين (Admin Dashboard) لإدارة جميع مكونات المتجر الإلكتروني بفعالية وأمان تين.

## 1. الإحصائيات والمؤشرات (Dashboard Analytics & Metrics)
* **عرض المؤشرات الرئيسية (Overview Metrics)**:
  * إجمالي الإيرادات (Total Revenue) لفترات زمنية مختلفة (اليوم، الأسبوع، الشهر، السنة).
  * عدد المبيعات وإجمالي الطلبات (Total Sales & Orders Count).
  * عدد العملاء المسجلين والنشطين (Active Customers Count).
  * المنتجات الأكثر مبيعاً (Top Selling Products).
* **التنبيهات الفورية والمعاينات (Real-time Indicators)**:
  * قائمة المنتجات ذات المخزون المنخفض (Low Stock Alert List).
  * الطلبات المعلقة التي تتطلب اتخاذ إجراء (`Pending Orders`).
  * جدول أحدث الطلبات (Recent Orders Table) مع إمكانية الوصول السريع والتحديث.

## 2. إدارة الأقسام والـ CRUD Operations
* **إدارة المنتجات والتصنيفات (Products & Categories)**:
  * إضافة، تعديل، حذف، وأرشفة المنتجات والصور المتعددة والمتغيرات (Variants).
  * إدارة هيكل التصنيفات (Categories, Subcategories) مع ترتيب العرض والرموز.
* **إدارة المخزون (Inventory Management)**:
  * تعديل رصيد المخزون مباشرة، ضبط حد التنبيه، وعرض سجل حركة المخزون (Audit Trail).
* **إدارة الطلبات (Orders Management)**:
  * استعراض الطلبات، تفاصيل المشتريات، تعديل حالة الطلب، إضافة رقم الشحن، وتوليد الفواتير (PDF Invoices).
* **إدارة العملاء (Customers Management)**:
  * استعراض قائمة العملاء، التفاصيل الشخصية، عناوين الشحن، سجل الطلبات، وحظر أو تفعيل الحسابات.
* **إدارة الكوبونات (Coupons Management)**:
  * إنشائ وتفعيل وتحديث وتعطيل كوبونات الخصم وحدود الاستخدام وتواريخ الصلاحية.
* **إدارة المراجعات والتقييمات (Reviews Moderation)**:
  * مراجعة تقييمات المنتجات، الموافقة عليها (Approve)، رفضها (Reject)، أو إخفائها (Hide).

## 3. الأمان وتأمين لوحة التحكم (Backend RBAC & Zero Trust)
* **الحماية على سيرفر الباك إند (Strict Backend Authorization)**:
  * عدم الاعتماد مطلقاً على إخفاء روابط أو صفحات Admin في Frontend كوسيلة أمان.
  * حماية جميع مسارات برمجيات الـ Admin (`/api/admin/*`) بواسطة Middleware مخصص يفحص `Role` في التوكين الموثق على السيرفر ويتحقق أنه `ROLE_ADMIN` أو `ROLE_SUPER_ADMIN`.
  * إرجاع `403 Forbidden` فورية مع تسجيل لمحاولات الوصول غير المصرح بها.
* **الأمان الإضافي للـ Admin**:
  * تفعيل Rate Limiting مشدد على API الـ Admin لمنع هجمات القوة الغاشمة (Brute Force).
  * تسجيل جميع الإجراءات التعديلية التي يقوم بها المدراء في جدول `AdminAuditLog` (IP, User ID, Action, Timestamp, Metadata).
