## EXECUTION PROTOCOL — MANDATORY

قبل تنفيذ هذا الأمر، يجب أولًا حفظ **هذا الأمر نفسه** كملف Markdown داخل:

`Antigravity_Prompts/`

### الترتيب الإجباري

1. أنشئ ملف Markdown داخل `Antigravity_Prompts/` بالاسم المحدد لهذا الأمر.
2. انسخ محتوى الأمر كاملًا إلى الملف بدون حذف أو اختصار أو إعادة صياغة.
3. تأكد أن الملف تم إنشاؤه بنجاح وأن محتواه كامل.
4. بعد إنشاء الملف، **لا تنفذ الأمر من رسالة الـChat مباشرة**.
5. افتح واقرأ ملف الـMarkdown الذي تم إنشاؤه من داخل `Antigravity_Prompts/`.
6. اعتبر هذا الملف هو **المصدر الوحيد للتنفيذ**.
7. نفّذ جميع التعليمات الموجودة داخل الملف بالترتيب.
8. لا تتجاوز أي خطوة.
9. لا تنتقل إلى خطوة لاحقة قبل إكمال والتحقق من الخطوة الحالية.
10. إذا حدث خطأ، أصلحه ثم أعد التحقق قبل الاستمرار.
11. في نهاية التنفيذ، تحقق أن ما تم تنفيذه مطابق تمامًا لمحتوى الملف.
12. لا تحذف ملف الأمر بعد التنفيذ؛ يجب أن يبقى داخل `Antigravity_Prompts/` كسجل موثق لما تم تنفيذه.

### قاعدة مهمة

**Chat → Create Markdown File → Read Markdown File → Execute → Validate**

وليس:

**Chat → Execute مباشرة**

هذه القاعدة إلزامية لكل أمر يتم إرساله ضمن هذا المشروع.
