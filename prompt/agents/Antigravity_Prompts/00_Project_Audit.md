# Project Audit

أنت تعمل على مشروع التجارة الإلكترونية الموجود في هذا المستودع.

قبل إجراء أي تعديل، قم بعمل Audit كامل للمشروع الحالي.

افحص جميع الملفات والمجلدات، خصوصًا:

* HTML
* CSS
* JavaScript
* JSON
* الصور والـassets
* README
* package files إن وجدت
* أي configuration موجود

حدد بالتفصيل:

1. الـFrontend الحالي.
2. طريقة عرض المنتجات.
3. طريقة إدارة الـCart.
4. طريقة الـCheckout.
5. مصادر البيانات.
6. أي APIs أو خدمات خارجية مستخدمة.
7. أي authentication موجود.
8. أي backend موجود.
9. أي database موجودة.
10. المشاكل المعمارية الحالية.
11. الملفات التي يمكن إعادة استخدامها.
12. الملفات التي يجب استبدالها.
13. الوظائف الموجودة فعليًا.
14. الوظائف الموجودة شكليًا فقط.

المشروع الحالي Prototype Static وليس Full-Stack، لذلك لا تفترض وجود Backend أو Database غير موجودين.

لا تبدأ إعادة البناء في هذه المرحلة.

أنشئ تقرير Audit داخل المشروع يوضح:

* Current Architecture
* Current Features
* Problems
* Technical Debt
* Reusable Assets
* Required Migration
* Recommended Target Architecture

لا تحذف أو تعدل الوظائف الحالية في هذه المرحلة إلا إذا كان ذلك ضروريًا لإنشاء تقرير دقيق.
