# Prompt 44 — Original Human-Crafted Storefront Design & Anti-AI UI Overhaul

## Mission

Perform a complete visual and UX redesign of the ecommerce storefront and relevant admin interfaces to eliminate the appearance of:

* AI-generated UI
* generic AI templates
* copied ecommerce layouts
* overused SaaS design patterns
* repetitive card-based interfaces
* visually generic component libraries
* designs that look like common online store templates
* designs that appear directly inspired by or cloned from existing major ecommerce platforms

The objective is to create a **distinctive, original, human-crafted ecommerce design system** with its own visual identity, layout language, spacing rhythm, component behavior, and merchandising presentation.

This is NOT a request to make the existing interface slightly different.

The design direction must be reconsidered at the structural level.

# 2. Core Design Principle

The result must look like it was designed intentionally by a professional product designer for this specific store.

It must NOT look like:

> "An AI generated ecommerce website."

Avoid generic visual formulas.

Do not simply use:

* gradient hero
* huge centered headline
* floating glass cards
* excessive rounded cards
* excessive shadows
* generic pastel gradients
* oversized decorative blobs
* random abstract shapes
* excessive glassmorphism
* identical cards everywhere
* excessive pills
* excessive badges
* generic dashboard KPI cards
* repetitive three/four-column layouts
* unnecessary animations
* stock-template hero sections

# 3. Do Not Copy Existing Major Ecommerce Platforms

Do not recreate the visual identity or exact layout patterns of:

* Noon
* Amazon
* Shopify
* eBay
* Temu
* AliExpress
* Shein
* Walmart
* Best Buy
* any other recognizable ecommerce platform

The application may follow established ecommerce usability principles.

However:

**visual execution, layout composition, spacing, typography, components, navigation treatment, and merchandising presentation must be independently designed.**

Do not reproduce:

* distinctive header structures
* recognizable navigation patterns
* signature colors
* exact product card styles
* exact category navigation treatment
* recognizable homepage compositions
* distinctive promotional layouts

# 4. Establish an Original Design Language

Create a coherent design language for this store.

Define:

### Typography

Choose a deliberate Arabic + English typography pairing.

The typography should communicate:

* clarity
* commerce
* trust
* modernity
* professionalism

Avoid using typography merely because it is popular in AI-generated website templates.

Use typography consistently across:

* headings
* prices
* labels
* product names
* navigation
* buttons
* admin interface

---

# 5. Original Layout System

Do not build every section using identical containers.

Introduce intentional variation while preserving consistency.

Examples of legitimate variation:

* asymmetric product compositions
* editorial product arrangements
* alternating content density
* variable section proportions
* carefully designed feature strips
* different merchandising layouts
* intentional whitespace
* visual hierarchy based on product importance

Do not introduce random layouts.

Every variation must have a UX or merchandising purpose.

---

# 6. Homepage Redesign

Completely rethink the homepage composition.

Do not preserve the existing homepage structure simply because it already works.

Keep the functionality but redesign the presentation.

The homepage should have a strong identity.

Consider a composition such as:

```text
Store Identity
        ↓
Primary Navigation
        ↓
Featured Commerce Moment
        ↓
Category Discovery
        ↓
Curated Product Story
        ↓
Secondary Product Collection
        ↓
Promotional / Value Proposition
        ↓
Additional Curated Sections
        ↓
Footer
```

The exact composition should be determined from the actual store's products and assets.

Do not blindly follow this structure.

---

# 7. Product Presentation

Product cards are one of the strongest indicators of template-like design.

Redesign them.

Avoid making every product card look like:

```text
┌─────────────┐
│    IMAGE    │
│             │
├─────────────┤
│ Product     │
│ $999        │
│ [Button]    │
└─────────────┘
```

Create a more intentional product presentation.

Use:

* strong image treatment
* intelligent typography hierarchy
* meaningful price emphasis
* subtle interaction
* contextual actions
* controlled metadata
* clean whitespace

Do not overload cards with information.

---

# 8. Product Image Treatment

The real product images already available in the project must remain the primary visual assets.

Do not replace them with AI-generated imagery.

Do not generate decorative product images.

Do not use random stock photography.

Use existing product images intelligently.

Consider:

* different aspect ratios where appropriate
* editorial crops
* large feature presentation
* contained product presentation
* image-first compositions
* subtle hover transitions

Never distort products.

# 9. Color System

Create an original color system.

Do not blindly use:

* default Tailwind blue
* generic purple gradients

The palette must be appropriate for ecommerce and the actual product inventory.

# 10. Avoid AI-Style Visual Clichés

Explicitly avoid:

### Glassmorphism everywhere

Do not make every element transparent/glass.

### Excessive gradients

Gradients should only exist when they have a real design purpose.

### Floating cards

Do not place every element inside floating rounded cards.

### Excessive border radius

Not every component needs extremely rounded corners.

### Excessive shadows

Avoid shadow-heavy interfaces.

### Decorative blobs

Do not add random abstract circles/blobs merely to make the page "look designed."

### Random illustrations

Do not add illustrations that have no product/UX purpose.

### Excessive pills

Do not turn every label into a pill.

### Excessive animation

Avoid animation for decoration.

Animations should communicate:

* state
* transition
* interaction
* hierarchy

# 14. Section Design

Each homepage section should have a clear reason to exist.

Avoid:

```text
Title
────────
4 identical cards
```

repeated 8 times.

Create visual hierarchy between sections.

For example:

* one major featured section
* one compact collection
* one editorial product arrangement
* one category discovery section
* one high-density shopping section

Use actual product data.

# 15. Merchandising

* dynamic sections
* categories

* real inventory
* real product images

---

# 16. Homepage Content Density

Avoid both extremes:

### Too empty

A page consisting of giant whitespace and a few oversized cards.

### Too crowded

A marketplace packed with dozens of badges and products.

Create a deliberate commerce rhythm.

The customer should quickly understand:

1. what the store sells
2. what is important
3. what can be purchased
4. where to browse
5. what is currently relevant
