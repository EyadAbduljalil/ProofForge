# 48. EXECUTION RULE

Do not implement everything blindly.

For every proposed capability:

```text
Does it already exist?
↓
How mature is it?
↓
What is missing?
↓
What value does it add?
↓
What dependencies does it require?
↓
What risks does it create?
↓
Can it be enforced?
↓
Can it be tested?
```

Only then implement.
