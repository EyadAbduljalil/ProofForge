# قائمة التحقق من الأداء والسرعة (Web Performance Checklist)

- [ ] **الصور والوسائط**:
  - [ ] تحويل الصور إلى صيغ WebP / AVIF الحديثة.
  - [ ] تفعيل التحميل الكسول `loading="lazy"` للصور الواقعة تحت خط الرؤية (Below the fold).
  - [ ] تحديد أبعاد صريحة للصور (`width` و `height`) لمنع تحولات التخطيط المفاجئة (CLS).
- [ ] **الأكواد والحزم**:
  - [ ] تقسيم الأكواد (Code Splitting) للمسارات والمكونات الكبيرة.
  - [ ] إزالة الاعتماديات غير المستخدمة والحزم الثقيلة.
  - [ ] تفعيل ضغط الاستجابات (Gzip / Brotli) على خادم الويب.
- [ ] **قواعد البيانات والتخزين المؤقت**:
  - [ ] وجود فهارس على كافة حقول الربط والتصفية.
  - [ ] تخزين مؤقت للاستعلامات المتكررة ذات التغيير البطيء.
