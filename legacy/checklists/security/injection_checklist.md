# قائمة التحقق من منع ثغرات الحقن (Injection Prevention Checklist)

- [ ] هل تم استبدال كافة استعلامات النصوص المجمعة المباشرة بـ Parameterized Queries؟
- [ ] هل تم تعقيم وتصفية حقول البحث والتصفية؟
- [ ] هل تم فحص مسارات رفع الملفات وتغيير أسماء الملفات ومنع تنفيذ الامتدادات الخطرة (`.php`, `.exe`, `.sh`)؟
- [ ] هل تم فحص أوامر النظام ومنع تمرير مدخلات المستخدم مباشرة إلى دوال `exec` أو `system`؟
