# قائمة التحقق من متانة المصادقة (Authentication Robustness Checklist)

- [ ] هل يتم فحص قوة كلمة المرور (طول لا يقل عن 12 حرفاً، أرقام، رموز)؟
- [ ] هل يتم حظر هجمات التخمين (Brute-force) عبر Rate Limiting صارم؟
- [ ] هل يتم تشفير الرموز السرية الحساسة أثناء التخزين؟
- [ ] هل روابط إعادة تعيين كلمة المرور تستخدم توكنات مشفرة لمرة واحدة تنتهي خلال مدة قصيرة (15 دقيقة)؟
