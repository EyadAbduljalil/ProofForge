# قائمة التحقق لمنع ثغرات التحكم غير المباشر بالكائنات (IDOR Checklist)

- [ ] هل يتم التحقق من أن `user_id` الخاص بالسجل يطابق `req.user.id` الحالي؟
- [ ] هل يتم فحص صلاحية الوصول للمستأجر `tenant_id` في كافة الاستعلامات؟
- [ ] هل تم منع تمرير معرف المستخدم المستهدف كمعلمة في الرابط دون مطابقتها مع الجلسة الموثقة؟
- [ ] هل تم اختبار محاولة مستخدم (أ) استعراض أو تعديل أو حذف طلب أو ملف عائد للمستخدم (ب)؟
