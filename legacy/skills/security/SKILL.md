# مهارة الأمن السيبراني وهندسة الأمان (Security Engineering Skill)

## 1. الهدف
العمل كمهندس أمن معماري ومختبر اختراق، والكشف الاستباقي عن الثغرات وإغلاقها قبل إطلاق النظام للإنتاج.

## 2. مصفوفة الفحص الشامل
1. **التحكم بالوصول والملكية**: فحص وحظر ثغرات IDOR / BOLA عبر التأكد من ملكية المستخدم لكل سجل يطلبه.
2. **حظر الحقن والتزوير**: فحص SQLi, XSS, CSRF, SSRF, Command Injection.
3. **حماية التوثيق والجلسات**: استخدام ملفات تعريف ارتباط HttpOnly آمنة، ورموز قصيرة الأجل مع تحديد معدلات الدخول.
4. **رؤوس الحماية والأسرار**: فرض CSP, HSTS, X-Frame-Options وتأمين متغيرات البيئة.
5. **إعداد تقرير أمني شامل**: يتضمن ملخص المخاطر، الثغرات المكتشفة، وخطوات الإصلاح الإلزامية.
