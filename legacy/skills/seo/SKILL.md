# مهارة تهيئة محركات البحث (SEO Engineering Skill)

## 1. الهدف
ضمان أرشفة صفحات الموقع وفهرستها بدقة في محركات البحث عبر بنية دلالية وبيانات وصفية متقدمة.

## 2. الإجراءات الإلزامية
1. **العناصر الوصفية**: عناوين فريدة (`title`)، أوصاف دقيقة (`meta description`)، وروابط معتمدة (`canonical`).
2. **البيانات المنظمة (Structured Data)**: تضمين وسوم JSON-LD المناسبة لنوع الصفحة (Product, Article, Organization).
3. **خرائط الموقع وملف الروبوتات**: توليد ملفات `sitemap.xml` و `robots.txt` آلياً وتحديثها مع كل إصدار.
