# قواعد المصادقة وتفويض الصلاحيات (Authentication & Authorization Rules)

## 1. نموذج الصلاحيات المرتكز على الأدوار والسمات (RBAC & ABAC)
- تعريف مصفوفة صلاحيات صارمة لكل دور (Role) مع فحص كل إذن بشكل صريح ومحدد (Least Privilege).
- التحقق المزدوج: فحص الدور العام + فحص ملكية السجل الفردي (Resource Ownership).
- الرفض الافتراضي لأي عملية غير محددة الصلاحيات مسبقاً.

## 2. إدارة كلمات المرور وبيانات الاعتماد
- تشفير كلمات المرور باستخدام خوارزميات بطيئة ومقاومة للهجمات مثل Argon2id أو Bcrypt بمعامل صعوبة كافٍ.
- تطبيق سياسات قوة كلمات المرور وفحصها ضد قوائم التسريبات المعروفة.
- فرض المصادقة متعددة العوامل (MFA/2FA) للمستخدمين ذوي الصلاحيات الإدارية والعمليات المالية الحساسة.

## 3. حماية الرموز والجلسات (Tokens & Sessions)
- استخدام رموز وصول قصيرة العمر (Short-lived Access Tokens) مع رموز تحديث آمنة (Rotated Refresh Tokens).
- إبطال الجلسة القديمة فوراً عند تسجيل الخروج أو تسجيل الدخول من جهاز جديد إذا تطلب النظام ذلك.
- فحص صحة الرمز وتوقيعه والتأكد من عدم وجوده في قائمة الرموز الملغاة (Token Revocation List).
