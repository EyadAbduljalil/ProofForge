# قواعد آلات الحالة وسلامة منطق الأعمال (State Machine & Logic Integrity Rules)

## 1. الانتقالات المعتمدة للحالات (Deterministic State Transitions)
- نمذجة كافة العمليات المعقدة (مثل حالات الطلب: مسودة ← معلق ← مدفوع ← قيد التجهيز ← مشحون ← مكتمل ← ملغي ← مسترجع) عبر آلات حالة منتهية (State Machines).
- حظر الانتقال غير المنطقي بين الحالات (مثل الانتقال من "ملغي" إلى "مشحون" مباشرة).
- تسجيل وتدقيق كل انتقال للحالة متضمناً هوية المنفذ، التوقيت، والسبب.

## 2. حماية العمليات المالية والمخزون
- حظر التعديل على أسعار المنتجات أو الشحن أو الضرائب بعد إنشاء الطلب وقبوله.
- حجز المخزون مؤقتاً أثناء مرحلة الدفع مع تحريره تلقائياً في حال انتهاء المهلة دون إتمام العملية.
- منع استخدام الكوبونات وقسائم الخصم بشكل متكرر أو بعد انتهاء صلاحيتها أو تجاوز شروطها عبر المعاملات الذرية.
