# قواعد التصميم المتجاوب (Responsive Design Rules)

## 1. استراتيجية الهاتف أولاً (Mobile-First Philosophy)
- بناء الهيكل الأساسي للواجهات ليتناسب أولاً مع أصغر الشاشات، ثم التوسع تدريجياً عبر نقاط التوقف (Breakpoints).
- نقاط التوقف المعتمدة:
  - Mobile: `< 640px`
  - Tablet: `640px - 1023px`
  - Laptop / Desktop: `1024px - 1439px`
  - Large Desktop: `>= 1440px`

## 2. سلامة التفاعل والتجربة اللمسية
- ضمان ألا يقل حجم أهداف اللمس (Touch Targets) عن `44x44px` على شاشات الهواتف والأجهزة اللوحية.
- منع التمرير الأفقي غير المقصود (No Unintended Horizontal Scrolling) وفحص كافة الجداول والنصوص والحاويات.
- تحويل الجداول المعقدة إلى بطاقات مكدسة أو توفير شريط تمرير أفقي مخصص ومنعزل بوضوح عند الشاشات الصغيرة.
- تكيف القوائم والأشرطة الجانبية (Drawers / Bottom Sheets / Collapsible Navigation) بانسيابية.
