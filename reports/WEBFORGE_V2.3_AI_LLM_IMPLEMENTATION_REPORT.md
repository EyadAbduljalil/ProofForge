## 2. تفاصيل المحركات والمكونات المنفذة (Implemented Engines)

تم بناء وتصدير المكونات الكنسية التالية:

### 2.1. محرك بروفايل الذكاء الاصطناعي وتدرج التعليمات (`ai-profile-boundary.js`)
- **توصيف النظام:** نمذجة تصريحية لهوية النموذج ومزوده وإصداراته والأدوات المصرح بها.
- **تدرج سلطة التعليمات (Instruction Hierarchy):** فرض سيادة تعليمات النظام غير القابلة للكسر (`SYSTEM_SOVEREIGN`) ومنع تجاوزها أو كسرها بواسطة مدخلات المستخدمين أو الوثائق الخارجية.

### 2.2. محرك فحص حقن الأوامر وسلامة السياق (`prompt-context-verifier.js`)
- **كشف حقن الأوامر (Prompt Injection):** كشف الأنماط المباشرة وغير المباشرة لمحاولات استخراج تعليمات النظام السرية أو تغيير قواعد العمل.
- **فحص الوثائق المسترجعة (RAG Context Integrity):** فحص محتوى الوثائق ومصادر الويب قبل حقنها في السياق للتأكد من خلوها من أوامر التوجيه الخبيثة.

### 2.3. مدقق استدعاء الأدوات والمعاملات (`tool-call-verifier.js`)
- **عزل المخرجات عن التنفيذ المباشر (`Model Output -> Action Boundary`):** حظر مطلق لأي تنفيذ عشوائي مباشر لمخرجات النموذج دون تدقيق مسبق.
- **تدقيق المعاملات والصلاحيات:** التحقق من مطابقة المعاملات للمخطط، ومنع حقن الأوامر والمسارات (`Command/Path Injection`)، وفرض فحص أدوار الفاعل.

### 2.4. مدقق منظومات الـ RAG والاستشهادات (`rag-citation-verifier.js`)
- **ربط الادعاءات بالمصادر:** التحقق من وجود استشهاد موثق لكل ادعاء عالي الأثر يصدره النموذج.
- **كشف الاستشهادات الملفقة (Fabricated Citations):** رصد الاستشهاد بمصادر وهمية أو مقتبسات غير موجودة في قاعدة المعرفة المعتمدة وإحباط الهلوسة.

### 2.5. مدقق الموافقة البشرية وعزل الوكلاء (`hitl-decision-tracer.js`)
- **الموافقة البشرية (Human-in-the-Loop):** فرض الموافقة المسبقة للإجراءات عالية الأثر ومنع الموافقة الذاتية (`Anti Self-Approval`).
- **عزل صلاحيات الوكلاء (Multi-Agent Boundary):** تدقيق تفويض الصلاحيات بين الوكلاء ومنع التوارث الصامت للصلاحيات أو تصعيد الامتيازات.
