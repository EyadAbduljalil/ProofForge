### 2. تدقيق آليات الدفاع ضد التزامن (Concurrency Defenses Audit)

| السيناريو المتزامن | آلية الحماية المطبقة | النتيجة المحققة |
| :--- | :--- | :--- |
| **الدفع المزدوج السريع (Double Spend / Fast Replay)** | مفاتيح عدم التكرار الذرية (`Atomic Idempotency Guard`) | منع تنفيذ المعاملة مرتين |
| **تحديث السجلات المتزامن (Optimistic Concurrency)** | استخدام مؤشرات الإصدار والتحقق الذري في الذاكرة / التخزين | منع الكتابة فوق التعديلات المتزامنة |
| **هجمات استنفاذ الموارد بالطلبات المتزامنة (DoS / Velocity)** | محدد السرعة ذو النافذة المنزلقة (`Sliding Window Rate Limiter`) | خنق الطلبات المفرطة مع رد `429 Too Many Requests` |
