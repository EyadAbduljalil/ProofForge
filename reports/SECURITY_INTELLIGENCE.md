### 2. مصفوفة نمذجة التهديدات والدفاعات (Threat Model & Mitigations Matrix)

| فئة التهديد (Threat Class) | ناقل الهجوم (Attack Vector) | آلية الدفاع المشفرة | حالة التحقق |
| :--- | :--- | :--- | :--- |
| **هجمات استخراج كلمات المرور** | هجمات القوة الغاشمة وبطاقات GPU | تجزئة **Scrypt** مع فحص التوقيت الثابت | مجاز |
| **الوصول المباشر غير المصرح (IDOR)** | التلاعب بمعرفات السجلات عبر الـ API | حراسة `OwnershipGuard` وفحص `tenant_id` خادمياً | مجاز |
| **تزوير إشعارات الدفع (Webhooks)** | محاكاة طلبات الدفع الخارجية | توقيع **HMAC SHA-256** ومقارنة مقاومة للتوقيت | مجاز |
| **حقن الأوامر لنماذج AI (Prompt Injection)** | حقن تعليمات خبيثة في نصوص المستخدمين | فحص الكلمات المفتاحية وقوائم الأدوات البيضاء | مجاز |
| **تزوير طلبات الخادم (SSRF)** | محاولة الوصول للشبكات الداخلية | حظر مجالات Private IP و Metadata Endpoints | مجاز |
| **هجمات إعادة التشغيل (Replay Attacks)** | إرسال نفس المعاملة المالية مرتين | محرك مفاتيح عدم التكرار الذري (`IdempotencyEngine`) | مجاز |
