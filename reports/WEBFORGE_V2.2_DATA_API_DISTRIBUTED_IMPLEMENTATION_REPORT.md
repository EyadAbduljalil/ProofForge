## 2. تفاصيل المكونات والمحركات المنفذة (Implemented Engines)

تم بناء وتصدير المكونات الكنسية التالية:

### 2.1. مدقق سلامة البيانات والترحيلات (`data-integrity-verifier.js`)
- **عقود البيانات والقيود:** فحص السجلات مقابل العقود التصريحية (الحقول الإلزامية، منع الفراغ غير القانوني، وتطابق الأنواع).
- **الروابط المرجعية والسجلات اليتيمة:** رصد السجلات اليتيمة (`Orphan Records`) والروابط المرجعية المنقطعة (`Broken References`) والتصادم في المفاتيح الفريدة.
- **تدقيق الترحيلات المبرمجة:** فحص ترحيلات البيانات والهياكل بين الإصدارات ($N \to N+1$) والتأكد من الحفاظ على البيانات ودعم التراجع الآمن (`Rollback Safe`).

### 2.2. مدقق عقود واجهات البرمجة والإصدارات (`api-contract-verifier.js`)
- **عقود نقاط النهاية:** تدقيق استدعاءات APIs (REST, GraphQL, RPC) مقابل المخططات المعتمدة، وفرض المصادقة وفحص الأدوار المصرح بها.
- **كشف التغييرات الكاسرة (Breaking Changes):** مقارنة إصدارات العقود آلياً واكتشاف حذف حقول الاستجابة أو فرض حقول إلزامية جديدة أو تشديد المصادقة المفاجئ.

### 2.3. مدقق الأحداث والرسائل والـ DLQ (`event-message-verifier.js`)
- **مخططات الأحداث:** تدقيق حقول حمولة الحدث وفرض معايير التتبع الموزع عبر معرفات الارتباط (`Correlation ID`) ومعرفات الأسباب (`Causation ID`).
- **سياسات الطوابير ومعالجة الرسائل المسمومة:** فحص عزل الرسائل المسمومة (`Poison Messages`) والتحويل الآمن إلى طوابير الرسائل الميتة (`Dead-Letter Queues`) عند استنفاذ محاولات المعالجة.

### 2.4. مدقق الويب هوك والتوقيع التشفيري (`webhook-verifier.js`)
- **التوقيع الرقمي المشفر (HMAC):** التحقق الرياضي في زمن ثابت (`Constant-Time Verification`) لمنع هجمات التوقيت.
- **مكافحة هجمات الإعادة (Anti-Replay Attack):** فحص انحراف الطابع الزمني (`Timestamp Drift`) وسجل بصمات التوقيعات لمنع إعادة إرسال الطلبات المعتمدة مسبقاً.

### 2.5. مدقق السلاسل الموزعة والاعتماديات الخارجية (`distributed-workflow-verifier.js`)
- **سلاسل التوزيع (Sagas):** تدقيق تسلسل خطوات المعاملات متعددة الخدمات والتأكد من وجود إجراءات تعويضية متسقة (`Compensating Actions`) لكل خطوة منجزة عند حدوث إخفاق في أي مرحلة.
- **مرونة الاعتماديات الخارجية:** محاكاة انقطاع الخدمات الخارجية والمهل الزمنية والتأكد من تفعيل البدائل الآمنة (`Graceful Fallbacks`) وتفادي الانهيار التتابعي.
