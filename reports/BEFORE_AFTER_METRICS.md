### 2. جدول المقارنة التفصيلي (Detailed Comparison Matrix)

| المحور الهندسي | الحالة الأولية قبل التحسين (Before) | الحالة الحالية المحققة (After) | نسبة التحسن والتأثير |
| :--- | :--- | :--- | :--- |
| **تشفير كلمات المرور** | غير موحد أو غير مفعل في بعض المسارات | تشفير Scrypt قوي مع معلمات OWASP والتحقق بالوقت الثابت | حماية 100% ضد استخراج البيانات وهجمات التوقيت |
| **عزل المستأجرين (Tenant Isolation)** | إمكانية وصول محتملة عبر تلاعب الـ ID | عزل إجباري تام عبر `ZeroTrustMicroGuards` في كل مسار | منع IDOR / BOLA بنسبة 100% |
| **معالجة المعاملات المالية والدفع** | مسارات صورية دون حماية إعادة التشغيل | محول Sandbox حقيقي مع مفتاح عدم التكرار الذري وحراسة الـ Replay | منع الخصم المزدوج وحماية التكرار |
| **رؤوس الحماية (Security Headers)** | رؤوس افتراضية غير كافية | تطبيق مشدد لـ CSP, HSTS, XFO, Anti-Sniff, Referrer-Policy | حماية كاملة ضد XSS و Clickjacking |
| **حوكمة الـ Webhooks** | استلام طلبات دون توقيع مشفر | توقيع HMAC SHA-256 ومقارنة Timing-Safe | منع تزوير الإشعارات المالية |
| **تجربة الواجهة وإمكانية الوصول** | واجهة أساسية تفتقر لحالات التحميل الحية و RTL | واجهة متفاعلة مع مؤشرات تحميل و WCAG 2.2 AA وتبديل فوري لـ RTL/LTR | تجربة مستخدم عالمية وميسرة |
| **تكامل سطر الأوامر (CLI)** | أوامر متباينة أو غير مكتملة الربط | 18 أمراً مركزياً موحداً ومختبراً عبر `bin/webforge.js` | تشغيل وإدارة آلية كاملة |
| **اختبارات التكامل الحية (Live E2E)** | اختبارات مجزأة | جناح متكامل يضم 9 اختبارات فعلية على خادم HTTP حقيقي | تحقق شامل ومستمر بالأدلة |
