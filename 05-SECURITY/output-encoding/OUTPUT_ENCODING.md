# الترميز السياقي للمخرجات ومنع حقن الواجهات (Context-Aware Output Encoding)

## 1. مبادئ الترميز السياقي (Context-Aware Encoding)
- لا يكفي تطبيق ترميز عام للمخرجات؛ بل يجب أن يتوافق الترميز بدقة مع السياق الذي سيتم إدراج البيانات فيه داخل وثيقة المتصفح:
  - **سياق كتل HTML (HTML Body)**: ترميز محارف `&`, `<`, `>`, `"`, `'` إلى كيانات HTML المعيارية (`&amp;`, `&lt;`, `&gt;`, `&quot;`, `&#x27;`).
  - **سياق سمات HTML (HTML Attributes)**: ترميز كافة المحارف غير الأبجدية الرقمية لحماية السمات المغلقة أو غير المغلقة بعلامات اقتباس.
  - **سياق JavaScript**: استخدام `JSON.stringify` مع معالجة وتفادي محارف `</script>` و `<!--`.
  - **سياق الروابط وعناوين URL**: ترميز المعاملات باستخدام `encodeURIComponent` والتحقق من البروتوكول المسموح (`https:`, `http:` فقط، وحظر بروتوكولات `javascript:` و `data:` تماماً).
  - **سياق CSS**: تجنب حقن مدخلات المستخدم مباشرة داخل وسوم الأنماط، واستخدام ترميز الهروب الست عشري الآمن.

---

## 2. سياسة أمان المحتوى (Content Security Policy - CSP)
- تفعيل ترويسة `Content-Security-Policy` صارمة لمنع تنفيذ الشيفرات البرمجية غير المصرح بها:
  - حظر `unsafe-inline` و `unsafe-eval`.
  - استخدام قيم الرموز العشوائية لكل طلب (`nonce-based CSP`) أو بصمات التجزئة المعتمدة (`hash-based CSP`).
  - تقييد مصادر تحميل الموارد والخطوط والصور والنصوص البرمجية إلى النطاقات الموثوقة صراحة.
  - تقييد إطارات التضمين عبر `frame-ancestors 'none'` لمنع هجمات اختطاف النقرات (Clickjacking).
