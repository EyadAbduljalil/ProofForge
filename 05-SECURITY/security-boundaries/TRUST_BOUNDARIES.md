# حدود الثقة وعزل المكونات (Trust Boundaries & Component Isolation)

## 1. تعريف حدود الثقة في المعمارية البرمجية
حد الثقة (Trust Boundary) هو الخط الفاصل بين بيئتين أو مكونين يمتلكان مستويات امتياز أو درجات موثوقية مختلفة. يتطلب عبور أي بيان أو استدعاء لهذا الحد إجراءات تحقق وتطهير وتفويض كاملة.

---

## 2. تقاطعات حدود الثقة الرئيسية

### أ) الحد بين المتصفح والخادم (Browser to Server Boundary)
- **طبيعة الحد**: انتقال من بيئة غير موثوقة بالكامل وخاضعة لسيطرة المستخدم إلى بيئة الخادم المحمية.
- **الضوابط الإلزامية عند العبور**:
  - التوثيق الصارم لكل طلب وفك تشفير الرموز بأمان.
  - التحقق من مطابقة المدخلات للمخطط المحدد وقائمة القيم البيضاء.
  - الحماية من هجمات CSRF و Replay Attacks.

### ب) الحد بين الخادم وخدمات الطرف الثالث (Server to Third-Party API Boundary)
- **طبيعة الحد**: تفاعل الخادم مع موفري خدمات خارجيين (بوابات دفع، مزودي ذكاء اصطناعي، خدمات سحابية).
- **الضوابط الإلزامية عند العبور**:
  - استخدام قنوات اتصال مشفرة وموثقة (mTLS أو توقيع الطلبات).
  - عدم الوثوق في الاستجابات الخارجية؛ فحصها ومعاملتها كمدخلات غير موثوقة.
  - تطبيق قواطع الدوائر (Circuit Breakers) والمهل الزمنية (Timeouts) لعزل أعطال الطرف الثالث.

### ج) الحد بين الخدمات المصغرة ومخازن البيانات (Internal Services to Data Store Boundary)
- **طبيعة الحد**: وصول الخدمات إلى السجلات التخزينية الحساسة.
- **الضوابط الإلزامية عند العبور**:
  - استخدام استعلامات مهيأة مسبقاً (Parameterized Queries).
  - تقييد صلاحيات مستخدم قاعدة البيانات بما يلائم وظيفة الخدمة المحددة (PoLP).
