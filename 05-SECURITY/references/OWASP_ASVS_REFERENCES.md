# المراجع والمعايير الأمنية العالمية (OWASP ASVS & Security References)

## 1. مراجع OWASP ASVS (Application Security Verification Standard v4.0)
يستند إطار أمان WebForge OS إلى متطلبات معيار التحقق الأمني للتطبيقات من OWASP:
- **V1: Architecture, Design and Threat Modeling**: متطلبات نمذجة التهديدات وحدود الثقة.
- **V2: Authentication Verification Standard**: متطلبات كلمات المرور، MFA، ومقاومة التخمين.
- **V3: Session Management Verification Standard**: متطلبات كعكات الجلسة وإبطال التوكنات.
- **V4: Access Control Verification Standard**: منع BOLA/IDOR والتفويض الخادمي الشامل.
- **V5: Validation, Sanitization and Encoding**: التحقق بالقوائم البيضاء والترميز السياقي.
- **V6: Stored Cryptography Verification Standard**: الخوارزميات الآمنة وإدارة المفاتيح.
- **V7: Error Handling and Logging**: منع تسريب التفاصيل الحساسة وتأمين السجلات.
- **V8: Data Protection**: حماية البيانات أثناء الراحة والنقل والتداول.
- **V13: API and Web Service Verification Standard**: أمان الواجهات البرمجية وتحديد المعدل.
- **V14: Configuration Verification Standard**: ترويسات الأمان وإعدادات البيئة الآمنة.

## 2. معايير NIST و CWE المعتمدة
- **NIST SP 800-63B**: إرشادات الهوية الرقمية ومتطلبات إدارة كلمات المرور والمصادقة.
- **NIST SP 800-57**: توصيات إدارة المفاتيح التشفيرية وتدويرها.
- **CWE Top 25 Most Dangerous Software Weaknesses**: قائمة أخطر 25 نقطة ضعف برمجية وخطط الوقاية منها.
