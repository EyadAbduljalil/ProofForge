# معايير جودة وتنسيق الكود (Code Style & Quality Standards)

## 1. الوضوح والبنية
- كتابة كود ذاتي التوثيق (Self-documenting Code) بأسماء دوال ومتغيرات دقيقة تعبر عن وظيفتها بدقة.
- منع الدوال الضخمة؛ تقسيم الوظائف إلى دوال نقية وصغيرة أحادية الغرض (Single Responsibility Principle).
- الالتزام بالتحقق الصارم من الأنواع ومنع استخدام `any` في مشاريع TypeScript.

## 2. أدوات الفحص والتنسيق الآلي
- ربط أدوات الفحص الساكن (ESLint / Biome / Prettier) وفحص الأمان في مسار التكامل المستمر (CI/CD).
- حظر رفع أو دمج أي كود يحتوي على تحذيرات أمنية أو أخطاء برمجية غير معالجة.
