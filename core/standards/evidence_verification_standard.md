# معيار التحقق المبني على الأدلة (Evidence-Based Verification Standard)

## 1. إلزامية الدليل القاطع
لا يُقبل أي تقرير أو ادعاء باكتمال الميزة أو أمانها دون تقديم أدلة فحص قابلة للتكرار تشمل:
- مخرجات الاختبارات الآلية (Test Execution Logs).
- مخرجات فحص الاستجابة للنقاط البرمجية مع رموز الحالة وتنسيق البيانات.
- لقطات الشاشة أو مخرجات فحص الواجهة عبر المتصفح لنقاط التوقف المختلفة.
- سجلات فحص الثغرات وصلاحيات الوصول.

## 2. حالات التقييم الرسمية
يجب تصنيف كل عنصر فحص بإحدى الحالات الصارمة التالية حصراً:
- `PASS`: تم الفحص بنجاح مع وجود دليل قاطع.
- `FAIL`: فشل الفحص مع توثيق سبب الفشل وخطوات إعادة الإنتاج.
- `BLOCKED`: تعذر الفحص لوجود مانع تقني خارجي موثق.
- `NOT TESTED`: لم يتم فحصه بعد ويجب جدولته فوراً.
- `NOT APPLICABLE`: غير منطبق على سياق المشروع الحالي مع بيان السبب.
