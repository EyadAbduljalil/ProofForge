# معايير إدارة النسخ والمهام (Git Workflow & Versioning Standards)

- **رسائل الالتزام القياسية (Conventional Commits)**:
  - `feat: إضافة بوابة الدفع الآمنة`
  - `fix: معالجة ثغرة التحقق من ملكية الطلب في الـ API`
  - `security: تعزيز رؤوس الأمان وتحديث سياسة CSP`
  - `refactor: إعادة تنظيم منطق حساب الضرائب في الخدمة المخصصة`
  - `test: إضافة اختبارات تكامل لآلة حالات الطلبات`
- **الفروع والمراجعة**: الالتزام بفروع الميزات (`feature/`, `fix/`, `security/`) مع فرض مراجعة الكود الصارمة قبل الدمج في الفرع الرئيسي.
