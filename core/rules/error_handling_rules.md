# قواعد معالجة الأخطاء والتسجيل (Error Handling & Logging Rules)

## 1. الحماية من تسريب البيانات الحساسة (Information Leakage Prevention)
- يُحظر نهائياً إرجاع تفاصيل الخطأ الداخلي (Stack Traces)، استعلامات SQL، مسارات الملفات في السيرفر، أو متغيرات البيئة إلى المتصفح أو المستخدم.
- توليد معرف خطأ فريد (`errorId / correlationId`) وإرجاعه للمستخدم للرجوع إليه عند التواصل مع الدعم الفني، مع تسجيل تفاصيل الخطأ كاملة في خادم التسجيل الداخلي.

## 2. التسجيل المنظم للمراقبة والأمان (Structured Audit Logging)
- تسجيل كافة الأحداث الأمنية والعمليات الحساسة بتنسيق JSON موحد:
  - عمليات تسجيل الدخول الفاشلة والناجحة.
  - محاولات الوصول غير المصرح بها (401 / 403).
  - العمليات المالية، وتغييرات الأسعار، والخصومات.
  - تعديل وحذف بيانات المستخدمين.
  - تغيير صلاحيات الأدوار الإدارية.
- إخفاء البيانات السرية (Sanitization & Masking) مثل كلمات المرور، وأرقام البطاقات الائتمانية، والرموز السرية من سجلات المراقبة (Logs).
