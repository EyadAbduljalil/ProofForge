# قواعد إمكانية الوصول والتوافق الشامل (Accessibility Rules - WCAG 2.2 AA)

## 1. البنية الدلالية وإدارة التباين
- استخدام العناصر الدلالية الصحيحة (`<main>`, `<nav>`, `<header>`, `<section>`, `<article>`, `<footer>`, `<button>`, `<a>`).
- الالتزام بنسب التباين اللوني المعتمدة:
  - النصوص العادية: نسبة تباين لا تقل عن `4.5:1`.
  - النصوص الكبيرة والعناصر الرسومية التفاعلية: نسبة تباين لا تقل عن `3:1`.

## 2. التنقل بلوحة المفاتيح وقارئات الشاشة
- إمكانية الوصول إلى كافة الوظائف والأزرار والنوافذ المنبثقة عبر لوحة المفاتيح حصراً (`Tab`, `Enter`, `Space`, `Escape`, `Arrow Keys`).
- توفير حالات تركيز مرئية وواضحة جداً (Visible Focus Rings) وتجنب `outline: none` دون توفير بديل بارز.
- إدراج سمات ARIA الصحيحة (`aria-expanded`, `aria-haspopup`, `aria-live`, `aria-label`) لكافة المكونات المخصصة وحبس التركيز داخل النوافذ المنبثقة (Focus Trapping).
- دعم تفضيل تقليل الحركة (`prefers-reduced-motion`) للمستخدمين الذين يعانون من مشاكل بصرية أو دوار الحركة.
