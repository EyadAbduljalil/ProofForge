# سياسة انعدام الثقة (Zero Trust Architecture Policy)

1. **التحقق الصريح دائماً**: مصادقة وتفويض كل طلب استناداً إلى كافة نقاط البيانات المتاحة (الهوية، الموقع، صحة الجهاز، سياق المورد).
2. **صلاحيات الحد الأدنى**: منح المستخدمين والخدمات الصلاحيات الدقيقة الضرورية فقط لتنفيذ المهمة، وإلغاؤها فور الانتهاء.
3. **افتراض الاختراق (Assume Breach)**: تصميم النظام بحيث يمنع الحركة الجانبية للمهاجمين عبر تجزئة الشبكة، تشفير الاتصالات الداخلية، وتقييد الصلاحيات بين الخدمات.
