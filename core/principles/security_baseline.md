# خط الأساس الأمني (Security Baseline)

## 1. نموذج انعدام الثقة (Zero Trust Architecture)
- لا يُوثق بأي مدخل صادر من المتصفح أو تطبيق العميل أو الروابط الخارجية.
- يتم التحقق من الهوية (Authentication) وتفويض الصلاحيات (Authorization) لكل طلب منفرد دون الاعتماد على حالة سابقة غير موثقة.

## 2. حماية تدفق البيانات والنقاط البرمجية
- **فحص الثغرات الحتمي**: الفحص التلقائي ضد:
  - التحكم غير المباشر بالكائنات (IDOR / BOLA)
  - حقن الأوامر وقواعد البيانات (SQL/NoSQL/Command Injection)
  - التزوير عبر المواقع (CSRF) والبرمجة النصية عبر المواقع (XSS)
  - تصعيد الصلاحيات الرأسي والأفقي (Privilege Escalation)
  - التعيين الجماعي للبيانات غير المصرح بها (Mass Assignment)
  - سباق العمليات (Race Conditions & Double Spending)
- **عزل الأسرار**: منع وضع مفاتيح API أو كلمات المرور أو أسرار التشفير داخل الكود نهائياً؛ الاعتماد الحصري على متغيرات البيئة المشفرة (Environment Variables).
- **رؤوس الأمان (Security Headers)**: تطبيق CSP, HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy على كافة الاستجابات.
