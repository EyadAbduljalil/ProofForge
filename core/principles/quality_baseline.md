# خط الأساس للجودة الهندسية (Quality Baseline)

## 1. معايير الكود والأداء
- كتابة كود واضح، قابل للاختبار، محدد الأنواع (TypeScript/Strict Typing).
- تجنب الاعتماديات الزائدة والحزم غير الضرورية (Zero Unnecessary Dependencies).
- ضبط مؤشرات الأداء الحيوية (Core Web Vitals):
  - سرعة تحميل المحتوى الأكبر (LCP < 2.5s)
  - التفاعل مع أول إدخال (INP < 200ms)
  - الاستقرار البصري التراكمي (CLS < 0.1)

## 2. معايير التغطية والاختبارات
- تغطية شاملة لمنطق الأعمال (Business Logic) باختبارات الوحدة (Unit Tests).
- اختبارات تكاملية (Integration Tests) للنقاط البرمجية والمسارات الحرجة.
- اختبارات تراجع دورية (Regression Tests) للتأكد من أن أي ميزة جديدة لا تكسر الوظائف السابقة.
