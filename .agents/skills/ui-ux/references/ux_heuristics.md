# ProofForge UI/UX Heuristics for Developer Platforms

1. **Visibility of System Status:** Always communicate progress and current state within 100ms.
2. **Match Between System and Real World:** Use established technical terms, avoid internal database column jargon.
3. **User Control and Freedom:** Provide clear undo, cancel, or edit mechanisms for all destructive actions.
4. **Consistency and Standards:** Follow platform conventions; do not reinvent basic input behaviors.
5. **Error Prevention:** Warn before permanent deletion; validate inputs inline before submission.
6. **Recognition Over Recall:** Keep actions and options visible; do not force users to memorize steps.
7. **Flexibility and Efficiency of Use:** Provide keyboard shortcuts for power users.
8. **Aesthetic and Minimalist Design:** Dialogs should not contain irrelevant or rarely needed information.
9. **Help Users Recognize and Recover from Errors:** Express errors in plain language, indicating precisely the problem and constructive resolution.
10. **Help and Documentation:** Provide contextual tooltips and immediate CLI help commands.
