# ProofForge Design Tokens Specification

## 1. Spacing & Sizing Scale (8px Grid)
| Token | Pixels | Rem | Primary Usage |
|---|---|---|---|
| `space-1` | 4px | 0.25rem | Micro-gap between icons and labels |
| `space-2` | 8px | 0.5rem | Compact padding, button inner gap |
| `space-3` | 12px | 0.75rem | Medium component inner padding |
| `space-4` | 16px | 1.0rem | Standard card padding & form row gap |
| `space-6` | 24px | 1.5rem | Section spacing within panels |
| `space-8` | 32px | 2.0rem | Layout container outer gutters |
| `space-12`| 48px | 3.0rem | Landing section vertical margins |

## 2. Typography Hierarchy
- `font-sans`: Geist, Inter, IBM Plex Sans Arabic (System Fallback: -apple-system)
- `font-mono`: JetBrains Mono, Geist Mono (Code, Hashes, API keys, Metrics)
