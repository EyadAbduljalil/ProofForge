# SEO & OpenGraph Metadata Example

```html
<head>
  <title>ProofForge — Deterministic AI Engineering Verification Framework</title>
  <meta name="description" content="Evidence-driven verification rules, claim governance, and security for AI-assisted engineering." />
  <link rel="canonical" href="https://proofforge.dev" />
  
  <!-- Open Graph -->
  <meta property="og:type" content="website" />
  <meta property="og:url" content="https://proofforge.dev" />
  <meta property="og:title" content="ProofForge — Deterministic AI Engineering Verification" />
  <meta property="og:description" content="Build with AI. Verify with Evidence." />
  <meta property="og:image" content="https://proofforge.dev/og-image.png" />
  
  <!-- Twitter -->
  <meta name="twitter:card" content="summary_large_image" />
  <meta name="twitter:title" content="ProofForge — AI Engineering Verification" />
  <meta name="twitter:image" content="https://proofforge.dev/og-image.png" />
</head>
```
