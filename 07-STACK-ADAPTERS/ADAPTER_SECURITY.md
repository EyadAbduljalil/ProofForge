# أمان المحولات ومكافحة حقن التوجيهات (Adapter Security & Prompt Defense)

## 1. التهديدات الأمنية لطبقة المحولات
- **حقن التوجيهات (Prompt Injection via Adapter Knowledge)**: إمكانية استغلال نصوص المحولات المستقاة من مصادر خارجية لمحاولة إعادة توجيه سلوك النموذج أو كسر الضوابط.
- **تضمين أسرار أو روابط مشبوهة**: احتواء الأمثلة على مفاتيح تجريبية أو روابط خبيثة.

---

## 2. الضوابط الدفاعية الحتمية
- **الفصل بين البيانات والتعليمات (Data vs Instruction Separation)**: تُعامل محتويات المحولات كبيانات وصفية تصريحية فقط، ويُحظر تقييمها كأوامر تنفيذية مباشرة.
- **حظر تجاوز الصلاحيات**: لا يملك المحول أي سلطة لمنح صلاحيات أو تجاوز بوابات الجودة أو تعديل نتائج الفحص.
- **التنقية التلقائية**: تجريد كافة أمثلة المحولات من أي أسرار أو بيانات اعتماد واقعية.
