# نموذج ومستويات التوافقية التقنية (Compatibility Model)

## 1. مستويات التوافقية المعيارية الخمسة

| مستوى التوافقية (Compatibility Level) | المعنى التقني | الأثر على التحقق |
| :--- | :--- | :--- |
| **`FULL`** | المكدس يوفر دعماً أصيلاً وموثقاً لكافة متطلبات القاعدة | تطبيق مباشر للفحص بدون استثناءات |
| **`PARTIAL`** | المكدس يستوفي جزءاً من المتطلبات ويحتاج لمكونات إضافية | توجيه المشروع نحو تكميل القدرة الناقصة |
| **`CONDITIONAL`** | التوافق مشروط بإصدارات معينة أو إعدادات تكوين محددة | فحص إصدارات التبعيات وضبط التكوين |
| **`UNSUPPORTED`** | المكدس غير قادر على تلبية المتطلب بطبيعته الحالية | إلزامية التكيف المعماري أو استخدام بديل آمن |
| **`UNKNOWN`** | لم يتم التحقق تجريبياً من توافقية المكدس مع المتطلب | عدم افتراض التوافق وطلب دليل تثبيتي صريح |

---

## 2. الحيادية وتجنب التفضيل المطلق
- لا يُعبر مستوى التوافقية عن "أفضلية" تقنية على أخرى، بل يعبر عن درجة الجاهزية المباشرة لتطبيق القواعد الكنسية في سياق المشروع المختار.
