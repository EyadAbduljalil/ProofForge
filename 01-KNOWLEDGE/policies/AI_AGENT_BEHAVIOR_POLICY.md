# سياسة سلوك وانضباط الوكلاء الأذكياء (AI Agent Behavior Policy)

## المعرّف: `POL-AI-AGENT-BEHAVIOR-001`
## الحالة: `ACTIVE`
## النطاق: كافة الوكلاء الأذكياء (Autonomous Agents) وأدوات التوليد البرمجي

---

## 1. الغرض
ضبط سلوك الوكلاء الأذكياء ونماذج التوليد البرمجي لمنع الهلوسة، ضمان التحقق القائم على الأدلة الواقعية، وحظر توليد الشيفرات الرديئة أو الوهمية (Anti-AI-Slop).

---

## 2. قواعد السلوك المعيارية (Operational Directives)

### 2.1 إلزامية الدليل الملموس (Evidence-Backed Assertions)
- يُحظر على الوكيل إعلان أي مهمة أو اختبار أو فحص أمني على أنه "ناجح" أو "مكتمل" دون إرفاق دليل ملموس (Output, Exit Code 0, Trace Log, Test Result).
- التوثيق وحده لا يُعد دليلاً كافياً لإثبات صحة العمل.

### 2.2 الالتزام بأقل تعديل آمن (Minimal Safe Diff)
- عند إصلاح أي خلل أو ثغرة، يجب تطبيق أقل قدر ممكن من التغيير البرمجي الآمن، وتجنب إعادة بناء الملفات بالكامل أو إدخال تغييرات هيكلية غير مبررة.

### 2.3 استشارة النواة المعرفية (Knowledge-First Execution)
- قبل البدء بأي فحص أو توليد كود، يجب على الوكيل استشارة القواعد المعيارية ذات الصلة في `01-KNOWLEDGE/rules/` وتطبيق معاييرها بدقة.

### 2.4 حظر التوليد الكسول والشيفرات الوهمية (Anti-AI Slop Directive)
- يُحظر استخدام تعليقات مثل `// TODO: Implement later` في المواضع الحرجة، أو استخدام مصفوفات وهمية لتجاوز الفحوصات، أو اختراع وظائف برمجية غير مدعومة.
- الشيفرة المولدة يجب أن تكون إنتاجية، مكتملة، وقابلة للاختبار فوراً.
