# هندسة الحركة والتحريك الهادف
## Motion Intelligence & Purposeful Animation

---

## 1. مبادئ التحريك الهادف (Purposeful Animation Principles)

1. **الحركة تخدم الفهم لا الإبهار (Motion Serves Cognition)**: الهدف من التحريك هو توضيح من أين جاء العنصر وإلى أين ذهب (مثل فتح القوائم، وتوسيع الأكورديون).
2. **السرعة والإيجاز (Brief & Snappy)**: تتراوح مدة التحريك القياسية بين `150ms` و `300ms`. حظر التحريكات البطيئة (أكثر من 500ms) التي تهدر وقت المستخدم.
3. **منع الحركات المستمرة المشتتة (No Perpetual Loops)**: تجنب الأشكال الدوارة أو النبضات المستمرة دون داعٍ على العناصر الثابتة.

---

## 2. منحنيات التسارع القياسية (Easing Curves)

```css
:root {
  /* خروج سلس للظهور */
  --ease-enter: cubic-bezier(0, 0, 0.2, 1);
  /* تسارع للاختفاء السريع */
  --ease-exit: cubic-bezier(0.4, 0, 1, 1);
  /* انتقال متزن للتفاعلات القياسية */
  --ease-standard: cubic-bezier(0.4, 0, 0.2, 1);
}
```
