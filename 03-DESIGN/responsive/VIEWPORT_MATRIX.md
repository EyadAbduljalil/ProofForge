# مصفوفة إطارات العرض العشرة القياسية
## The 10 Canonical Viewports Matrix

---

## 1. مصفوفة إطارات العرض المعتمدة (Canonical Viewports)

يحدد WebForge OS عشرة إطارات عرض قياسية لاختبار وضمان جودة التجاوب البصري:

| # | العرض (Width) | الفئة والجهاز النموذجي | السلوك المتوقع للتخطيط والملاحة | كثافة المحتوى وحجم اللمس |
| :- | :--- | :--- | :--- | :--- |
| **1** | **`320px`** | الشاشات الصغيرة جداً (Legacy / Mini Phones) | عمود فردي، ملاحة قابلة للطي (Drawer/Menu)، إخفاء الهوامش الزائدة | Touch: 44px, Font: 15px, Compact |
| **2** | **`375px`** | الهواتف القياسية المدمجة (e.g. iPhone SE) | عمود فردي، أزرار كاملة العرض، تباعد 12px-16px | Touch: 44px, Font: 16px, Compact |
| **3** | **`390px`** | الهواتف الحديثة الشائعة (e.g. iPhone 13/14/15) | عمود فردي مع بطاقات مدمجة، ملاحة سفلية أو رأسية | Touch: 44px, Font: 16px, Standard |
| **4** | **`414px`** | الهواتف الكبيرة (e.g. Plus / Max / Ultra) | عمود فردي مع شبكات صور مصغرة 2x2 عند الحاجة | Touch: 44px, Font: 16px, Comfortable |
| **5** | **`768px`** | الأجهزة اللوحية الوضع الرأسي (Tablet Portrait) | عمودان (2 Columns)، شريط جانبي قابل للطي، جداول قابلة للتمرير | Touch: 44px, Font: 16px, Split Layout |
| **6** | **`834px`** | الأجهزة اللوحية المتوسطة (e.g. iPad Pro 11") | عمودان إلى ثلاثة، ظهور أشرطة الأدوات العلوية الموسعة | Pointer/Touch, Font: 16px, Multi-col |
| **7** | **`1024px`** | الأجهزة اللوحية الأفقية والحواسيب المدمجة | شريط جانبي دائم (Persistent Sidebar)، شبكة 3 أعمدة | Pointer: 36-40px, Font: 16px, Standard Desktop |
| **8** | **`1280px`** | الشاشات المكتبية القياسية (Standard Desktop) | تخطيط كامل متعدد الأعمدة (Sidebar + Main + Aside) | Pointer: 36px, Font: 16px, Full Grid |
| **9** | **`1440px`** | الشاشات العريضة الحديثة (Wide Desktop) | حاوية مركزية محددة العرض الأقصى لمنع التمدد المفرط | Pointer: 36px, Max-Width Container |
| **10**| **`1920px+`**| الشاشات فائقة الاتساع (Ultra-Wide / 4K) | الحفاظ على اتساع الحاوية المركزية (`max-width: 1440px - 1600px`) | Balanced Margins, Scanability Protected |

## 2. جدول التحقق من المكونات عبر إطارات العرض

- **الجداول المعقدة (Data Tables)**:
  - الشاشات الصغيرة (< 768px): تمرير أفقي داخلي آمن أو تحويل الخلايا إلى بطاقات ملخصة.
  - الشاشات الكبيرة (>= 768px): عرض كامل للأعمدة مع فرز وتصفية مرئية.
- **القوائم وشريط الملاحة (Navigation)**:
  - الشاشات الصغيرة (< 1024px): قائمة قابلة للفتح والإغلاق مع إمكانية الوصول بلوحة المفاتيح.
  - الشاشات الكبيرة (>= 1024px): قائمة أفقية أو شريط جانبي دائم.
