# مراجع ومصادر منظومات التصميم المعمارية
## Design System & Open Standards References

---

## 1. المعايير والمراجع الدولية المعتمدة

1. **W3C Design Tokens Community Group (DTCG)**:
   - مسودة المواصفة القياسية لتنسيق توكنات التصميم المشتركة وتبادلها عبر JSON.
2. **W3C WAI-ARIA Authoring Practices Guide (APG)**:
   - الأنماط المعيارية لتطبيق لوحة المفاتيح وسمات ARIA للنوافذ، القوائم، التبويبات، والجداول.
3. **Open Type & CSS Fonts Module Level 4**:
   - المعايير المنظمة لخطوط الويب المتغيرة (Variable Fonts) والمقاييس الطباعية.
