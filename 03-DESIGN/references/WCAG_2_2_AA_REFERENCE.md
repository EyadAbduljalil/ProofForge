# المرجع المعياري لإمكانية الوصول WCAG 2.2 AA
## Web Content Accessibility Guidelines (WCAG) 2.2 Canonical Reference

---

## 1. المرجع الرسمي والمعايير الصادرة عن W3C

- **المعيار الحاكم**: W3C Recommendation — Web Content Accessibility Guidelines (WCAG) 2.2 (Published October 2023).
- **مستوى الامتثال المستهدف**: **Level AA**.

---

## 2. معايير WCAG 2.2 الجديدة والمطبقة في WebForge OS

1. **SC 2.4.11 / 2.4.12 Focus Not Obscured (Minimum / Enhanced)**:
   - عندما يتلقى عنصر واجهة التركيز عبر لوحة المفاتيح، يجب ألا يتم حجبه أو إخفاؤه بالكامل خلف شريط علوي أو نافذة منبثقة غير نموذجية.
2. **SC 2.5.7 Dragging Movements**:
   - أي إجراء يعتمد على السحب والإفلات (Drag & Drop) يجب أن يوفر بديلاً بسيطاً بنقرة واحدة (Single Pointer Alternative) مثل أزرار الصعود والهبوط.
3. **SC 2.5.8 Target Size (Minimum)**:
   - مساحة الهدف التفاعلي يجب أن تكون على الأقل `24 × 24 CSS pixels` أو محاطة بمسافة كافية تمنع النقر العرضي الخاطئ.
4. **SC 3.3.7 Redundant Entry**:
   - المعلومات التي أدخلها المستخدم مسبقاً في نفس الجلسة يجب ملؤها تلقائياً أو إتاحتها للاختيار بدلاً من إجباره على إعادة كتابتها.
