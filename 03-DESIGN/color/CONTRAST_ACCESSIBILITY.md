# معايير تباين الألوان وإمكانية الوصول البصري
## Color Contrast & Visual Accessibility Specification

---

## 1. متطلبات معيار WCAG 2.2 AA الصارمة

يلتزم WebForge OS بالتحقق الحسابي الدقيق لنسب التباين بين النص وخلفيته وفق معايير W3C WCAG 2.2 AA:

| فئة العنصر | الحد الأدنى لنسبة التباين (WCAG 2.2 AA) | معيار التميز المعماري (WCAG AAA) |
| :--- | :--- | :--- |
| **النصوص العادية (Body & Small Text)** | **`4.5 : 1`** | `7.0 : 1` |
| **النصوص الكبيرة (Large Text >= 18pt أو >= 14pt Bold)** | **`3.0 : 1`** | `4.5 : 1` |
| **عناصر التحكم التفاعلية وحواف الإدخال (UI Components)** | **`3.0 : 1`** | `4.5 : 1` |
| **مؤشرات التركيز (Focus Indicators)** | **`3.0 : 1`** مقابل الخلفية المجاورة | `4.5 : 1` |

---

## 2. التحقق من مؤشرات التركيز (Focus Ring Visibility)

- يُمنع منعاً باتاً إلغاء مؤشر التركيز باستخدام `outline: none;` دون توفير بديل بصري متباين وواضح.
- التنسيق القياسي لمؤشر التركيز:
  ```css
  :focus-visible {
    outline: 2px solid var(--border-focus, #0284c7);
    outline-offset: 2px;
    box-shadow: 0 0 0 4px rgba(2, 132, 199, 0.2);
  }
  ```

---

## 3. حالات التعطيل (Disabled States)

- على الرغم من أن معيار WCAG يعفي العناصر المعطلة من شرط 4.5:1، إلا أن WebForge OS يوصي بالحفاظ على تباين مقروء لا يقل عن **`2.5:1`** مع إرفاق السمة `aria-disabled="true"` وتوضيح سبب التعطيل للمستخدم.
