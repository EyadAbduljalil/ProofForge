# دليل معايير الطباعة والخطوط
## Typography Architecture & Font Standards

---

## 1. فلسفة الطباعة (Typography Philosophy)

الطباعة هي العمود الفقري للتواصل البصري في واجهات المستخدم. تهدف قواعد الطباعة في WebForge OS إلى:
- **المقروئية القصوى (Readability & Legibility)** عبر جميع الشاشات وظروف الإضاءة.
- **التسلسل الهرمي المنطقي (Logical Hierarchy)** الذي يمكن مسحه وقراءته بسهولة بالعين.
- **احترام التعدد اللغوي (Multilingual Harmony)** ودعم الخطوط العربية واللاتينية بتناغم كامل.

---

## 2. مكدس الخطوط البديلة (Fallback Font Stack)

يجب توفير مكدس خطوط قوي يضمن سرعة العرض واستقرار التخطيط وتجنب قفزات النصوص (FOUT/FOIT):

```css
/* مكدس الواجهات الحديثة - عربي ولاتيني متناغم */
--font-sans: system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", 
             "Noto Sans Arabic", "Tajawal", "Cairo", sans-serif;

/* مكدس النصوص البرمجية والبيانات الرقمية */
--font-mono: ui-monospace, "Cascadia Code", "Source Code Pro", Menlo, Consolas, monospace;
```

---

## 3. الأبعاد والنسب القياسية للنصوص (Type Measures & Line Height)

- **طول السطر المثالي (Measure)**: يتراوح بين 45 إلى 75 حرفاً في السطر للنصوص المقروءة، وتجنب الأسطر فائقة الاتساع التي تشتت التركيز.
- **ارتفاع السطر الدلالي (Line Height Ratio)**:
  - للعناوين الكبيرة (`h1`, `h2`): 1.15 إلى 1.25.
  - للفقرات والنصوص الأساسية (`body`): 1.5 إلى 1.65 (مع زيادة طفيفة للخطوط العربية لضمان وضوح الحركات والتشكيل).
  - للنصوص الصغيرة والتسميات التوضيحية (`caption`, `metadata`): 1.3 إلى 1.4.
