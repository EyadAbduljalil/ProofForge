# مواصفة معيار إمكانية الوصول الشاملة WCAG 2.2 AA
## Web Content Accessibility Guidelines (WCAG) 2.2 Level AA Specification

---

## 1. المبادئ الأربعة الحاكمة لإمكانية الوصول (POUR Principles)

يلتزم WebForge OS بالتحقق الكامل من المبادئ الأربعة لمعيار W3C WCAG 2.2 AA:
1. **القابلية للإدراك (Perceivable)**: يجب تقديم المعلومات ومكونات واجهة المستخدم بطرق يمكن لجميع المستخدمين إدراكها بحواسهم (نصوص بديلة، نسب تباين لا تقل عن 4.5:1، دعم تكبير الشاشة حتى 200%).
2. **القابلية للتشغيل (Operable)**: يجب أن تكون كافة عناصر التحكم قابلة للاستخدام الكامل عبر لوحة المفاتيح دون فخاخ تركيز (Keyboard Traps)، مع إتاحة وقت كافٍ للقراءة والتفاعل.
3. **القابلية للفهم (Understandable)**: يجب أن تكون النصوص مقروءة وواضحة، وسلوك الواجهة متوقعاً، والمساعدة في تجنب الأخطاء وتصحيحها متاحة دائماً.
4. **المتانة والتوافق (Robust)**: يجب أن يكون الكود دلالياً وقوياً بما يكفي لتفسيره بدقة عبر مختلف البرامج المساعدة وقارئات الشاشة (Screen Readers).

---

## 2. معايير النجاح الأساسية لمستوى WCAG 2.2 AA (Key Success Criteria)

| معيار النجاح (SC) | الوصف الهندسي | التطبيق في WebForge OS |
| :--- | :--- | :--- |
| **1.1.1 Non-text Content** | توفير نص بديل ذي معنى لكافة الصور والأيقونات الوظيفية. | استخدام `alt` دلالي للصور وإخفاء العناصر التزيينية بـ `aria-hidden="true"`. |
| **1.3.1 Info and Relationships** | نقل العلاقات الهيكلية عبر HTML الدلالي. | استخدام عناصر HTML5 (`<main>`, `<nav>`, `<header>`, `<table>`, `<fieldset>`). |
| **1.4.3 Contrast (Minimum)** | تباين الألوان 4.5:1 للنصوص العادية و 3:1 للنصوص الكبيرة. | فحص آلي وتطبيقي لكافة التوكنات اللونية. |
| **2.1.1 Keyboard** | إمكانية الوصول لكافة الوظائف عبر لوحة المفاتيح. | فحص مفاتيح `Tab`, `Enter`, `Space`, `Escape`, والأسهم. |
| **2.1.2 No Keyboard Trap** | منع احتجاز التركيز داخل أي مكون فرعي. | تحرير التركيز عند إغلاق النوافذ المنبثقة أو الوصول لحدودها. |
| **2.4.7 Focus Visible** | وضوح مؤشر التركيز البصري. | حظر `outline: none` وتوفير حلقة تركيز متباينة بسماكة 2px على الأقل. |
| **2.5.8 Target Size (Minimum)** | الحد الأدنى لأهداف النقر واللمس (WCAG 2.2 الجديد). | مساحة نقر لا تقل عن `24px × 24px` مع مسافة محيطة، و `44px × 44px` للهواتف. |
| **3.3.2 Labels or Instructions** | توفير ملصقات وإرشادات واضحة لحقول النماذج. | ربط `<label for="...">` بكل حقل إدخال صراحة. |
| **4.1.2 Name, Role, Value** | تعيين الاسم والدور والقيمة لكل عنصر تفاعلي. | التسميات الصريحة وأدوار ARIA الدقيقة. |
