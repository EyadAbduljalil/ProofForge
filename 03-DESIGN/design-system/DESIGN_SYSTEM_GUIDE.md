# دليل معايير منظومة التصميم المعمارية
## Design System Architectural Guide

---

## 1. فلسفة منظومة التصميم (Design System Philosophy)

تعمل منظومة التصميم في WebForge OS كطبقة توجيهية وحوكمية تضمن تناسق واجهات المستخدم، ووضوح التسلسل الهرمي، وسهولة الصيانة.

المنظومة مصممة لتكون **حيادية تقنياً (Stack-Agnostic)**، بحيث يمكن تطبيق مفاهيمها وتوكناتها في أي بيئة تشغيل (Vanilla CSS, CSS Modules, Styled Components, Tailwind, Design Systems Frameworks) دون فرض مكتبة معينة.

---

## 2. طبقات التوكنات الثلاث (Three-Tier Token Architecture)

```text
+-------------------------------------------------------------+
| 1. توكنات القيم الخام (Raw / Global Tokens)                |
|    - تمثل القيم المطلقة: أرقام، درجات ألوان، مسافات.        |
|    - مثال: --color-blue-500: #2563eb; --space-4: 1rem;       |
+-------------------------------------------------------------+
                              |
                              v
+-------------------------------------------------------------+
| 2. توكنات المعنى الدلالي (Semantic Tokens)                 |
|    - تربط القيمة الخام بوظيفة أو معنى داخل الواجهة.         |
|    - مثال: --color-primary: var(--color-blue-500);          |
|            --surface-danger: var(--color-red-100);          |
+-------------------------------------------------------------+
                              |
                              v
+-------------------------------------------------------------+
| 3. توكنات المكونات المحددة (Component-Scoped Tokens)        |
|    - تخصص المتغيرات لعنصر محدد لسهولة إعادة الاستخدام.       |
|    - مثال: --btn-bg: var(--color-primary);                  |
|            --dialog-border: var(--border-subtle);           |
+-------------------------------------------------------------+
```

---

## 3. محاور منظومة التصميم الأساسية (Core Design Pillars)

1. **سلم المسافات والأبعاد (Spacing & Sizing Scale)**:
   - اعتماد مقياس نسبي متناسق (مبني على مضاعفات 4px / 0.25rem أو 8px).
   - تجنب القيم العشوائية غير المعيارية (مثل `padding: 13px;` أو `margin-top: 37px;`).
2. **سلم الاستدارة والحدود (Radii & Borders)**:
   - تصنيف الاستدارات دلالياً (`--radius-sm`, `--radius-md`, `--radius-lg`, `--radius-full`).
   - الاستخدام المتزن لزوايا المكونات وتجنب التدوير المفرط غير المبرر.
3. **الارتفاع والظلال (Elevation & Shadows)**:
   - ربط الظلال بالعمق البصري للطبقات (`--elevation-1` للبطاقات، `--elevation-3` للنوافذ المنبثقة).
   - تجنب الظلال المتوهجة غير الطبيعية إلا إذا كانت إشارة تفاعل محددة.
4. **الانتقالات والحركة (Transitions & Durations)**:
   - سرعات قياسية سريعة وواضحة (100ms - 250ms) وحظر الحركات البطيئة المعطلة لسرعة التفاعل.
