# مصفوفة الحالات التفاعلية الشاملة للمكونات
## Comprehensive Component States Matrix

---

## 1. فلسفة اكتمال الحالات (Total State Completeness)

يُحظر في WebForge OS تصميم أي مكون أو شاشة بالاعتماد على الحالة الافتراضية فقط (Happy Path). كل عنصر تفاعلي أو تدفق بيانات يجب أن يحتوي على تعريف بصري وهندسي لجميع حالاته الممكنة:

---

## 2. مصفوفة الحالات الأربع عشرة المعتمدة (14 Canonical States)

| # | اسم الحالة | التوصيف البصري والتفاعلي | السلوك وإمكانية الوصول |
| :- | :--- | :--- | :--- |
| **1** | **`Default` (الافتراضية)** | المظهر المستقر والأساسي للمكون قبل أي تفاعل. | حالة الاستعداد الطبيعية. |
| **2** | **`Hover` (التحويم)** | تغميق/تفتيح طفيف للسطح بنسبة 5-10% لتأكيد القابلية للتفاعل. | يظهر عند مرور مؤشر الفأرة فقط دون لمس. |
| **3** | **`Focus / Focus-Visible`** | حلقة تركيز متباينة 2px مع إزاحة 2px. | يتم تفعيلها فوراً عند التنقل بلوحة المفاتيح. |
| **4** | **`Active / Pressed` (الضغط)** | ضغط طفيف للأسفل (Scale 0.98 أو إزاحة 1px) مع تغميق إضافي. | يوفر استجابة فورية للحظة النقر. |
| **5** | **`Selected / Active Tab`** | تمييز واضح بلون السمة الأساسية أو خط سفلي/جانبي بارز. | `aria-selected="true"` أو `aria-current="page"`. |
| **6** | **`Disabled` (المعطلة)** | خفض الشفافية أو مظهر خافت مع مؤشر `not-allowed`. | `aria-disabled="true"` وتوضيح سبب التعطيل. |
| **7** | **`Loading / Pending` (التحميل)** | استبدال النص بدوران خفيف أو شريط تقدم. | `aria-busy="true"` ومنع النقرات المتكررة. |
| **8** | **`Success` (النجاح)** | لون أخضر دلالي وأيقونة تأكيد نصية. | `role="status"` للإخطار الصوتي. |
| **9** | **`Warning` (التحذير)** | لون برتقالي/كهرماني دلالي مع إشارة توضيحية. | تنبيه المستخدم قبل المضي قدماً. |
| **10**| **`Error / Invalid` (الخطأ)** | إطار أحمر دلالي ورسالة خطأ توضيحية مرافقة. | `aria-invalid="true"` و `aria-describedby`. |
| **11**| **`Empty` (الفراغ)** | رسالة ودية توضح عدم وجود بيانات مع زر إجراء للبدء. | منع ظهور شاشات رمادية ميتة خالية من المحتوى. |
| **12**| **`Partial / Indeterminate`** | حالة وسيطة لمربعات الاختيار (بعض العناصر مختارة). | `aria-checked="mixed"`. |
| **13**| **`Offline` (انقطاع الاتصال)** | شريط تنبيهي علوي يوضح فقدان الشبكة ومحاولة إعادة الاتصال. | حفظ التعديلات محلياً وإخطار المستخدم. |
| **14**| **`Permission Denied` (مرفوض)** | رسالة صريحة تشرح غياب الصلاحية مع خيار طلب الوصول. | توجيه المستخدم للمسار الإداري الصحيح. |
