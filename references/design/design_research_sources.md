# دليل مصادر البحث والتغذية البصرية المتخصصة (Design Research Sources Guide)

## 1. فهرس المزودات والأدوار التخصصية

### 1.1. الواجهات والمكونات المعيارية (UI / Components)
- **21st.dev** ([https://21st.dev/](https://21st.dev/)):
  - استكشاف مكونات واجهة المستخدم التفاعلية.
  - أنماط التركيب والتنفيذ التقني لمكونات React و CSS.

### 1.2. أنظمة التصميم والتوجهات البصرية (Design Systems / Visual Direction)
- **Refero Design** ([https://styles.refero.design/](https://styles.refero.design/)):
  - مراجع الأنظمة البصرية الحقيقية لكبرى التطبيقات.
  - فحص التناغم الطباعي، شبكات التباعد، والتدرجات المنطقية.

### 1.3. تكوين المواقع الكاملة والتسلسل التحريري (Full Website Inspiration)
- **SiteInspire** ([https://www.siteinspire.com/](https://www.siteinspire.com/)):
  - تكوين المواقع المتكاملة والتسلسل الهرمي التحريري.
- **Land-book** ([https://land-book.com/](https://land-book.com/)):
  - صفحات هبوط ومواقع متخصصة حسب النطاق (SaaS, Ecommerce, Portfolios).
- **Godly** ([https://godly.design/](https://godly.design/)):
  - التوجهات الإبداعية والتجريب البصري والتفاعل الراقي.
- **Awwwards** ([https://www.awwwards.com/](https://www.awwwards.com/)):
  - الحركات المتقدمة، التفاعلات الثلاثية الأبعاد، والابتكار الفني.

### 1.4. صفحات الهبوط والتحويل (Landing Pages & Hero Sections)
- **Supahero** ([https://supahero.io/](https://supahero.io/)):
  - أنماط أقسام البطل وتجاوز النمطية المكررة.
- **Lapa Ninja** ([https://www.lapa.ninja/](https://www.lapa.ninja/)):
  - تركيب أقسام صفحات الهبوط وأنماط التحويل التسويقي.

### 1.5. تدفقات المستخدم وتجربة المنتجات الحقيقية (Product UX & User Flows)
- **Mobbin** ([https://mobbin.com/](https://mobbin.com/)):
  - تدفقات تسجيل الدخول، النماذج، صفحات الدفع، وتجارب تطبيقات الجوال الحقيقية.

### 1.6. الألوان والحركات (Color & Motion)
- **Coolors** ([https://coolors.co/](https://coolors.co/)):
  - بناء لوحات الألوان المتناغمة والعلاقات التباينية.
- **Motion.dev** ([https://motion.dev/](https://motion.dev/)):
  - مراجع حركات الواجهات، الإيماءات، والتنقلات السلسة.

---

## 2. قواعد الاستخدام والامتثال
1. يُمنع التجميع العشوائي (Reference Mixing) بأخذ عناصر متفرقة من مصادر مختلفة ودمجها بلا لغة تصميم موحدة.
2. يتم استخلاص المبادئ أولاً، ثم بناء نظام التصميم المخصص للمشروع قبل البدء في رسم الصفحات.
